# Aether Shell showcase production

This directory records the public production brief and evidence contract for T36. It contains no
private desktop captures, process inventory, local paths, or borrowed reference images. Raw footage
and runtime metadata remain in a per-user local output directory until every frame has passed privacy
review and the owner selects media for publication.

The owner requires **100/100 on the complete exported film**, with every blocking gate passed. This
is stricter than the generic motion-design brief's default target. The score is a project acceptance
rubric, not an external certification or a guarantee of subjective taste. See
[`06_SCORECARD.md`](06_SCORECARD.md).

Current source includes a native clean-session runner, isolated scene preparation, DXGI acquisition,
validated frame archives and offline recipes, CPU/GPU compositors, H.264/AAC and WIC GIF export, plus
an original procedural soundtrack. Provider-scoped frame IDs reduce redundant reads/uploads;
bounded lossless tile acquisition has passed focused tests and completed a real take. See the
[capture architecture and limits](../docs/showcase-capture.md).

Two real takes were rejected: one had a black wallpaper and approximately 17 captured samples per
second; the next had a black wallpaper, 12.44 samples per second, a 5.95-second gap and unrelated
private content in its final frame. Neither may become public media. The owner confirmed the scenic
wallpaper was restored. Later takes exposed cursor, orientation, GIF color, toast and ending defects;
the correction record distinguishes them from the latest candidate.

The latest candidate is C5FF64A3, a 1,030-frame 1920×1080 progressive BT.709 MP4 with uniform 60-FPS
timestamps and measured AAC stereo. Complete decode and two independent contact-sheet reviews cover
all frames, with critical images inspected at full resolution. No unrelated content was observed in
that scope. Source samples average 57.37/s and remain distinct from actual desktop updates and the
authored output rate. See [QC](07_QC_REPORT.md), [corrections](05_CORRECTIONS.md) and the
[asset register](03_ASSET_REGISTER.md).

Normal-speed playback/listening and the full 60-check/ten-gate acceptance remain unverified; no
100/100 score is claimed. Per-frame surface guards cannot guarantee allowed-app contents or remove
window-change races. Keep local artifacts private; do not replace missing evidence with synthetic
product screens, rejected footage or unmeasured quality claims. The matching GIF is not yet optimized
for web delivery.
