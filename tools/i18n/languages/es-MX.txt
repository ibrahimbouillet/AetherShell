## setup

en: Quit Aether Shell, turn this off in Settings > Desktop, or open "Restore Windows taskbar" in the Start menu to get the Windows taskbar back.
tr: Sal de Aether Shell, desactívalo en Configuración > Escritorio, o abre "Restore Windows taskbar" en el menú Inicio para recuperar la barra de tareas de Windows.

en: After you sign in or unlock your PC, Aether Shell writes a short greeting by hand. Type the name it should greet you with, or leave it empty for a simple hello.
tr: Al iniciar sesión o desbloquear la PC, Aether Shell escribe a mano un breve saludo. Escribe el nombre con el que debe saludarte, o déjalo vacío para un simple hola.

en: Optional, for example a first name. It stays on this PC in your Aether Shell settings and is never sent anywhere. Change it, or turn the welcome off, in Settings > Welcome.
tr: Opcional, por ejemplo un nombre de pila. Se queda en esta PC, en tu configuración de Aether Shell, y nunca se envía a ninguna parte. Cámbialo o desactiva la bienvenida en Configuración > Bienvenida.

en: Installing accepts the startup choice above. The launcher can restart Aether Shell after a crash, with a bounded retry limit. Quit and Restore Windows taskbar remain available. Weather is off by default. Unsigned binaries may trigger a Windows SmartScreen warning.
tr: Al instalar aceptas la opción de inicio anterior. El iniciador puede reiniciar Aether Shell después de un error grave, con un número limitado de intentos. Salir y Restore Windows taskbar siguen disponibles. El clima está desactivado de forma predeterminada. Los archivos sin firmar pueden provocar una advertencia de Windows SmartScreen.
