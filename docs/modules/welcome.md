# Module: welcome

The optional handwritten greeting after sign-in and unlock (FR-041, [ADR 0013](../decisions/0013-transient-session-welcome.md), D53, D54).

| File | Role |
| --- | --- |
| `Handwriting.h/.cpp` | Pure: composes ink from the stroke table, with the calligraphic pen (lean, reach, swelling down strokes), timing, lifts and a layout as large as the room allows. |
| `HandwritingStrokes.inc` | Generated by `tools/handwriting/strokes.py`, where the strokes are authored. Do not edit it by hand. |
| `WelcomeController.h/.cpp` | Pure lifecycle: sign-in, unlock, lock and its cover, skip, readiness and the deadline. |
| `WelcomeWindow.h/.cpp` | The transient composition window, `PaintHandwriting` and the kept ink layer. |
| `WelcomeBackdrop.h/.cpp` | Reads and blurs the desktop picture; the pure veil and fill rules. Only the application calls `LoadDesktopBackdrop`; tests hand in their own pictures. |

The application owns the session wiring (`ShellApplication`): it maps session notifications to the
controller, decodes the picture on its worker, checks readiness on a 50 ms timer while a greeting shows and
Windows' session state every 500 ms while a cover waits, and registers Escape as a temporary hotkey. Only a production-instance session greets, which includes a private `--data-dir` trial; test instances
never do.

To change the handwriting, edit the strokes, inspect a preview, then regenerate the table:

```powershell
python tools/handwriting/strokes.py --preview out.png "Salut Ibrahim"
python tools/handwriting/strokes.py --cpp > src/welcome/HandwritingStrokes.inc
```

Privacy: the name is entered by the person, kept in `settings.json`, and never logged, transmitted or read
from the Windows account. The desktop picture is read only while a greeting is due, held in memory until it
ends, and never logged, stored or transmitted. Settings warnings name the field, never its value, and the window text never
carries it.

Evidence and limits: TEST_STATUS S-061, S-062. Real sign-in, the cover at a real lock and the owner's
acceptance are separate checks.
