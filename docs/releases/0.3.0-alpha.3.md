# Aether Shell 0.3.0-alpha.3 — Alpha 3

The third alpha brings the V3 design and interaction work: one glass design across every Aether
window, a fluid Settings, Aether's own Quick Settings, Dock window previews, real notifications and
hidden icons from the Top Bar, rounded maximized windows and Auto-Hide for both bars. Like the earlier
alphas, it is an experimental manual-install preview, not a fully qualified Windows shell
replacement or a complete Version 1 release.

## Download

- [Windows x64 setup](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.3.0-alpha.3/AetherShell-0.3.0-alpha.3-win-x64-setup.exe)
- [SHA-256 checksums](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.3.0-alpha.3/AetherShell-0.3.0-alpha.3-checksums.txt)

Compare the downloaded setup's SHA-256 with the checksums file before running it. Setup is per-user
and does not require administrator rights. Windows may show a SmartScreen warning because this alpha
does not have an Authenticode publisher signature.

## Highlights

- **Auto-Hide** for the Dock and the Top Bar, each with its own setting (off by default). A bar slides
  away while an application window covers it and returns when the pointer rests on its screen edge;
  it stays while in use and on the desktop. Maximized windows then use the full screen.
- **Notifications and calendar** from the Top Bar date and time (Win+N on Windows 11, Win+A on
  Windows 10), without Aether reading, clearing or badging any notification.
- **Hidden icons**: a Top Bar chevron opens Windows' own notification-area overflow directly below it
  and closes it again on the next click.
- **Aether Quick Settings**: a rebuilt panel with tiles, two pages, sliders, media controls and detail
  views for Wi-Fi, Bluetooth, accessibility and sound output. Windows 11's own Quick Settings remains
  available through a Top Bar setting.
- **Dock window previews**: genuine previews of an app's windows on hover, each closable on its own,
  with markers that grow from dot to pill.
- **Rounded maximized windows** with a thin continuous rim while Aether replaces the taskbar, undone
  on exit; Settings draws its own rounded maximized frame.
- **One glass design**: Settings, menus, setup, maintenance, the updater and confirmations share the
  neutral frosted material, controls, typography and motion, with smooth, coherent Settings scrolling.

The complete list is in the [changelog](../../CHANGELOG.md). Fresh presentation media for Alpha 3 has

## Upgrading from Alpha 2

Setup can install over an existing per-user installation and keeps the previous version for
rollback; the Alpha 2 to Alpha 3 upgrade itself has not yet been run on a real installation. Saved
preferences load unchanged. New settings start at their defaults: Auto-Hide off, the hidden-icons
chevron shown, and Aether's Quick Settings used for the grouped Top Bar action.

## Important limits

- Explorer remains the Windows shell. Aether Shell does not register as the native taskbar in Windows
  Settings, replace `explorer.exe`, or change the Winlogon shell.
- Windows 11 x64 is the development target. Windows 10 2004+ and ARM64 are not runtime-tested.
- Auto-Hide edge reveal with real applications, the hidden-icons route on other Windows builds,
  rounded corners for every window-rendering family, multi-monitor and DPI changes, real hardware
  controls and assistive technologies are not fully qualified.
- Automatic updates remain unavailable; no unsigned update manifest is published.
- Windows schedules sign-in applications; startup order and delay are not guaranteed, and a native
  taskbar may appear before startup or during failure recovery.
- Read the complete [known limitations](../../KNOWN_LIMITATIONS.md) and
  [installation guide](../../INSTALLATION.md) before installing.
