# Aether Shell 3.3 (0.3.3-alpha.3)

Version 3.3 brings a much steadier desktop, complete touch, a handwritten welcome and a Wi-Fi list in Quick Settings. Like
the earlier versions, it is an experimental manual-install preview, not a fully qualified Windows shell replacement.

## Download

- [Windows x64 setup](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.3.3-alpha.3/AetherShell-0.3.3-alpha.3-win-x64-setup.exe)
- [SHA-256 checksums](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.3.3-alpha.3/AetherShell-0.3.3-alpha.3-checksums.txt)

Compare the downloaded setup's SHA-256 with the checksums file before running it. Setup is per-user and does not require
administrator rights. Windows may show a SmartScreen warning because this version does not have an Authenticode publisher
signature.

## Highlights

- **Handwritten welcome:** after you sign in or unlock, Aether writes a greeting across your blurred desktop picture with a
  calligraphic pen, in French or English, with your name if you enter one. It takes about two seconds and any touch, click
  or Escape skips it. Settings → Welcome turns it off.
- **Wi-Fi networks in Quick Settings:** see the networks around you and their signal, and join one, with its password if
  it needs one. Windows keeps the password. Names and passwords are never logged or sent.
- **Complete touch:** pan long lists and Settings pages with a finger, with glide and elastic ends; hold for menus; pan up
  and down through Quick Settings; swipe in from a screen edge for a hidden bar.
- **Sliders that follow the hand:** press anywhere on a Settings slider to move it there and keep dragging. Brightness
  follows the thumb, and a value you asked for no longer jumps back while Windows catches up.
- **Quicker Top Bar:** with Auto-Hide on, the bar comes out half a second after the pointer reaches its place, and passing
  through does nothing. Back on the desktop, both bars return.
- **Rounded corners between the bars:** with both bars hidden, a maximized window simply takes the whole screen. Between the
  bars, browsers keep their rounded corners instead of losing them.
- **Steadier:** a window that stops responding no longer holds up the others. Settings tells you what Windows will really do
  at sign-in and repairs a lost startup entry. Many smaller corrections are in the [changelog](../../CHANGELOG.md).

## Upgrading

Setup can install over an existing per-user installation and keeps the previous version for rollback. Saved preferences load
unchanged, and the welcome is on until you turn it off. This upgrade has not yet been run on a real installation.

## Important limits

- Explorer remains the Windows shell. Aether Shell does not register as the native taskbar in Windows Settings, replace
  `explorer.exe`, or change the Winlogon shell.
- Windows 11 x64 is the development target. Windows 10 2004+ and ARM64 are not runtime-tested.
- Not yet proven in real use: joining a Wi-Fi network through Aether, the welcome at a real sign-in (Windows decides when
  Aether starts, so the desktop can show first), and multi-monitor setups, where the welcome covers the primary monitor only.
- A reported problem of browser pages going blank after changing Auto-Hide has not been reproduced, so it is not known to be
  fixed. With Auto-Hide on, a pointer resting on a browser's tabs for half a second brings the Top Bar over them.
- Automatic updates remain unavailable; no unsigned update manifest is published.
- Read the complete [known limitations](../../KNOWN_LIMITATIONS.md) and [installation guide](../../INSTALLATION.md) before
  installing.
