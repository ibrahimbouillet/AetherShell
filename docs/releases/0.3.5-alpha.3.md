# Aether Shell Alpha 3, version 3.5 (0.3.5-alpha.3)

Version 3.5 leaves your applications alone at the top of the screen, closes panels as soon as you use anything else, finds Windows' own
tools in Search, and makes the welcome personal from the start: setup asks for your name, your wallpaper shows behind the writing even
when its file is gone, and the pen flows more lightly. Like the earlier versions, it is an experimental manual-install preview, not a fully
qualified Windows shell replacement.

Version 3.4 was prepared as a test build and never published; everything in it is part of 3.5.

## Download

- [Windows x64 setup](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.3.5-alpha.3/AetherShell-0.3.5-alpha.3-win-x64-setup.exe)
- [SHA-256 checksums](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.3.5-alpha.3/AetherShell-0.3.5-alpha.3-checksums.txt)

Compare the downloaded setup's SHA-256 with the checksums file before running it. Setup is per-user and does not require
administrator rights. Windows may show a SmartScreen warning because this version does not have an Authenticode publisher
signature.

## Highlights

- **Your name in the welcome, from the first time:** setup has an optional field for the name the welcome greets you with, so the
  greeting is no longer just "Salut" until you find Settings. Installing over an existing version shows the name already saved.
- **Your wallpaper behind the welcome, always:** when the picture's file had been moved or deleted after you set it, the welcome showed a
  black screen. It now uses the copy Windows keeps of the picture on screen.
- **A lighter pen:** the soft dark edge under the ink used to be blurred again, whole, for every frame. Only the part around the newest
  ink is now, about a twentieth of the work, for the same picture. Each greeting also notes in the log how smoothly it was written.
- **The Top Bar stays out of your applications:** with Auto-Hide on, it answers only to the very top row of pixels of the screen, after a
  quarter of a second. Anything lower, tabs and close buttons included, is the application's.
- **Panels close when you use anything else:** a click or a touch elsewhere, switching application, or Escape closes Quick Settings and
  Search at once, whether or not Windows had given them the focus.
- **Search finds Windows' own tools:** Device Manager, Services, Event Viewer, Computer Management, Task Scheduler, Disk Management and the
  Control Panel's items. Every match can be reached, and every opening starts empty.
- **No more doubled pages in Settings:** after a check for updates, scrolling could show the page's rows twice over. Fixed.
- **Updates says what is true:** when a newer version is out, Settings names it and tells you how to install it, instead of "Failure: Validation".
- **A more fluid welcome:** the pen is still quick, and you can now watch each shape being drawn: its speed changes slowly, it sets off and
  lands gently, and the ink settles to its width just behind it. The letters are the same.
- **The README shows five real desktops** in a short slideshow, with each picture at full size one click away.

Everything new in [3.3](0.3.3-alpha.3.md) is included.

## Upgrading

Setup can install over an existing per-user installation and keeps the previous version for rollback. Saved preferences load
unchanged; a name typed in setup replaces the welcome's name only when it differs. The upgrade from the 3.4 test build has run once on a
real installation; an upgrade straight from 3.3 or Alpha 3 has not.

## Important limits

- Explorer remains the Windows shell. Aether Shell does not register as the native taskbar in Windows Settings, replace
  `explorer.exe`, or change the Winlogon shell.
- Windows 11 x64 is the development target. Windows 10 2004+ and ARM64 are not runtime-tested.
- Not yet proven in real use: the welcome at a real lock and sign-in with this version, panel closing under a real hand, in particular by
  touch; joining a Wi-Fi network through Aether; and multi-monitor setups, where the welcome covers the primary monitor only.
- With Auto-Hide on, a pointer held on the very top pixel of a maximized window's close button for a quarter of a second still brings the Top Bar.
- A reported problem of browser pages going blank after changing Auto-Hide has not been reproduced, so it is not known to be fixed.
- Automatic updates remain unavailable; no unsigned update manifest is published.
- Read the complete [known limitations](../../KNOWN_LIMITATIONS.md) and [installation guide](../../INSTALLATION.md) before
  installing.
