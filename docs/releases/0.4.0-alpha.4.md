# Aether Shell Alpha 4 (0.4.0-alpha.4)

Alpha 4 gives Aether Shell a second look, *Liquid*: clear water glass over your desktop. It also speaks the languages
Windows speaks, and finds what Start finds. The weather has a window of its own, the Top Bar can be plain text on your
desktop, and Aether starts sooner after you sign in. Like the earlier versions, it is an experimental manual-install
preview, not a fully qualified Windows shell replacement.

## Download

- [Windows x64 setup](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.4.0-alpha.4/AetherShell-0.4.0-alpha.4-win-x64-setup.exe)
- [SHA-256 checksums](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.4.0-alpha.4/AetherShell-0.4.0-alpha.4-checksums.txt)

Compare the downloaded setup's SHA-256 with the checksums file before running it. Setup is per-user and does not require
administrator rights. Windows may show a SmartScreen warning because this version does not have an Authenticode publisher
signature.

The `AetherShell-language-<code>.json` files of this release are the interface languages. You do not need to download
them yourself: setup and Aether Shell fetch the ones they need. They are listed in the checksums file too.

## Highlights

- **Two styles, Liquid and Grain:** choose in Settings > Appearance. Liquid is clear glass over a blur layer whose
  strength and colour you set, with light along its edges. Grain is the frosted material of the earlier versions.
  The Dock, the Top Bar, panels, Search, the weather and Settings all take the style you choose, and the welcome arrives
  in it.
- **Smart transparency in Settings:** in Liquid, the Settings window stays clear where it shows nothing. Under its text
  and controls it blurs what lies behind: fully over other windows and desktop icons, lightly over the desktop picture,
  fading at the edges, so text behind never reads through its own. You can turn it off in Settings > Appearance.
- **41 languages:** the 38 languages Windows 11 offers, plus Bengali, Hindi and Urdu. Aether follows your Windows
  display language, or the one you choose in Settings > Language. Languages are no longer all in the setup. Each one
  (about 70 KB) is downloaded from this release when it is needed, and checked before it is used. Setup and Aether
  download the languages your Windows has, so Aether changes language when Windows does. Settings > Language shows each
  language's size and adds any other.
- **Search finds what Start finds by name:** applications, Windows Settings pages, Control Panel items, files and
  folders. Moving the pointer never changes what Enter opens.
- **The weather, precise and animated:** your location to about 100 m when you allow it (rounded to about 10 km
  otherwise), animated illustrations, and a weather window from the Top Bar with the sky hour by hour, 24 hours, 7 days,
  the sun's path, a map with live temperatures and a city search.
- **The Top Bar as text on the desktop:** an option shows the clock and status as plain text over your wallpaper,
  without a bar.
- **A Dock you can stretch:** a dragged icon never leaves the Dock; the Dock stretches after it and springs back.
- **Maximized windows keep rounded corners** next to the Dock and the Top Bar, and the corners go under any window you
  open in front.
- **A sooner start:** Aether starts at sign-in through its own task in Task Scheduler instead of waiting for Windows'
  startup programs. The switch you see stays in Settings and in Task Manager's Startup apps. Each start now notes in the
  log how long it took.
- **Lighter at rest:** less work while nothing changes, and lighter switches between styles.

## Known limitations

- The translations were made carefully but have not all been reviewed by native speakers. Right-to-left languages read
  right to left but the layout is not mirrored yet.
- Smart transparency is in the Settings window only. It needs Windows 11 with transparency effects on.
- See [KNOWN_LIMITATIONS.md](https://github.com/ibrahimbouillet/AetherShell/blob/v0.4.0-alpha.4/KNOWN_LIMITATIONS.md).
