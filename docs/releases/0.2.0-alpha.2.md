# Aether Shell 0.2.0-alpha.2 — Alpha 2

The second public alpha introduces the V2 Dock-and-Top-Bar experience. This is an experimental
manual-install preview, not a fully qualified Windows shell replacement or a complete Version 1
release.

## Download

- [Windows x64 setup](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.2.0-alpha.2/AetherShell-0.2.0-alpha.2-win-x64-setup.exe)
- [SHA-256 checksums](https://github.com/ibrahimbouillet/AetherShell/releases/download/v0.2.0-alpha.2/AetherShell-0.2.0-alpha.2-checksums.txt)

Compare the downloaded setup's SHA-256 with the checksums file before running it. Setup is per-user
and does not require administrator rights. Windows may show a SmartScreen warning because this alpha
does not have an Authenticode publisher signature.

## Highlights

- Reversible visual replacement of the Windows taskbar, enabled by default when Aether Shell starts,
  with a persistent opt-out and recovery helper.
- Bottom Dock with pinned and running applications, drag reordering with spring settling, Start/Search/
  Task View actions, profile-aware icons when Windows supplies them, and application-attention cues.
- Top Status Bar with proportional network/weather/status glyphs and neutral translucent material.
- Grouped quick controls and consent-gated automatic Windows location for weather.
- Updated status rendering, battery thresholds and reduced-motion-aware interaction paths.
- Disclosed sign-in startup in fresh setup, with an opt-out and preservation of existing choices.
- Stable installed launcher with three bounded abnormal-exception retries and independent taskbar
  recovery. Intentional Quit, maintenance and ordinary startup errors stop supervision.
- Live observed audio changes update an open Quick Controls slider without waiting for its periodic
  media refresh.

Fresh presentation media is planned as a later addition to the [versioned gallery](../media/README.md).
No older/rejected recording is included as this release's presentation.

## Important limits

- Explorer remains the Windows shell. Aether Shell does not register as the native taskbar in Windows
  Settings, replace `explorer.exe`, or change the Winlogon shell.
- Windows 11 x64 is the current development target. Windows 10 2004+ and ARM64 were not runtime-tested
  for this release.
- Real hardware controls, Windows location/forecast, accessibility across all assistive technologies,
  multi-monitor/DPI changes, and every taskbar/Explorer crash-recovery path are not fully qualified.
- Automatic updates are unavailable in this alpha. No unsigned update manifest is published.
- Windows schedules sign-in applications; startup order and delay are not guaranteed. Aether does
  not use a service, elevation, realtime priority or an immortal process. A native taskbar may appear
  before startup or during failure recovery.
- Read the complete [known limitations](../../KNOWN_LIMITATIONS.md) and [installation guide](../../INSTALLATION.md)
  before installing.
