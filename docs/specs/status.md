# Module specification: status (phase A)

Read `AGENTS.md` first; it states the rules every implementer follows. This is the work order that
was given to the implementing engineer. The real headers in the repository are authoritative where
they differ from names used here.

Module: status (directory src/status, target aether_status; deps: aether_core aether_diagnostics aether_platform windowsapp user32 plus any system libs you need).
Your files: src/status/** EXCEPT src/status/audio/** and EXCEPT src/status/StatusTypes.h (read-only contract owned by the lead; propose changes in followUps); tests/unit/status/**, tests/integration/status/**, docs/modules/status.md.
Contract: src/status/StatusTypes.h (IStatusProvider<Snapshot>, ClockSnapshot, BatterySnapshot, KeyboardSnapshot, NetworkSnapshot). Implement:
1. ClockProvider : IStatusProvider<ClockSnapshot>. Real time from GetSystemTimePreciseAsFileTime/GetLocalTime and GetDynamicTimeZoneInformation (zone name, DST active). Emit at the next second or minute boundary depending on SetResolution(Seconds|Minutes) (default Minutes) using a waitable timer (or threadpool timer) armed for the next boundary on a dedicated thread: no busy polling, no drift. NotifyTimeChanged() (the app calls it on WM_TIMECHANGE or WM_SETTINGCHANGE "intl") recomputes immediately and re-reads the time zone. Survive sleep/resume (re-arm when the observed time jumps).
2. ClockFormatter (pure, testable): FormatTime(snapshot, ClockFormatOptions{TimeFormat System|Hours12|Hours24, showSeconds}, localeName) and FormatDate(snapshot, DateStyle WeekdayDayMonth|Short|Long, localeName) using GetTimeFormatEx/GetDateFormatEx (default LOCALE_NAME_USER_DEFAULT). Hours12/Hours24 overrides build explicit format pictures that keep the locale's separators and AM/PM designators. WeekdayDayMonth is a short localized form like "Sat 17 Oct" (format picture "ddd d MMM"). Unit-test with fixed snapshots and fixed locales (en-US, fr-FR, de-DE).
3. BatteryProvider : IStatusProvider<BatterySnapshot>. Use Windows.System.Power.PowerManager via C++/WinRT (BatteryStatus, PowerSupplyStatus, RemainingChargePercent, RemainingDischargeTime, EnergySaverStatus and their Changed events) with GetSystemPowerStatus as a cross-check and fallback. No battery: state Unavailable, batteryPresent=false, never 0%. Unknown percent (255) becomes nullopt. Map Charging, Discharging, Full (100% on AC, not charging) and NotCharging (on AC, idle below 100). Deduplicate identical snapshots. Factor a pure mapping function from raw readings to a snapshot and unit-test it (no battery, unknown values, charging, full, AC idle, energy saver).
4. KeyboardProvider : IStatusProvider<KeyboardSnapshot>. The displayed language is the input language of the thread that owns the foreground window: GetKeyboardLayout(GetWindowThreadProcessId(GetForegroundWindow(), nullptr)). Convert LOWORD(HKL) with LCIDToLocaleName; label is the upper-case ISO 639-1 code (LOCALE_SISO639LANGNAME; fall back to the 3-letter name); display name via LOCALE_SLOCALIZEDDISPLAYNAME; layout name best effort from the registry (HKLM\SYSTEM\CurrentControlSet\Control\Keyboard Layouts\<KLID>, Layout Display Name through SHLoadIndirectString, else Layout Text). Re-query on EVENT_SYSTEM_FOREGROUND (SetWinEventHook, WINEVENT_OUTOFCONTEXT, on the provider's own thread with a message loop) plus a lightweight 1 s timer that only compares the HKL: Windows has no documented system-wide notification when another process changes its input language; document this. Emit only on change. Without a foreground window (secure desktop), fall back to the provider thread's layout with fromForegroundWindow=false. Document the limitations: console windows, elevated windows, IME conversion modes are not represented, the per-app input setting.
5. NetworkProvider : IStatusProvider<NetworkSnapshot>. Use Windows.Networking.Connectivity: NetworkInformation::GetInternetConnectionProfile(), the NetworkStatusChanged event, ConnectionProfile.GetNetworkConnectivityLevel() (None, LocalAccess, ConstrainedInternetAccess, InternetAccess), IsWlanConnectionProfile / IsWwanConnectionProfile, NetworkAdapter().IanaInterfaceType() (6 Ethernet, 71 Wi-Fi) and GetSignalBars() (only when it returns a value). No profile: kind None, connectivity None. Do NOT read or show the Wi-Fi SSID or profile name (Windows 11 24H2+ treats it as location data); leave profileName empty and document why. Debounce bursts of NetworkStatusChanged (about 300 ms) and re-query on a worker thread, never on the UI thread. No polling loop.
General: blocking, COM or WinRT work runs on each provider's own thread or WorkerPool (MultiThreaded apartment). Stop() unregisters events and hooks, stops timers, joins threads, and guarantees no listener call after it returns. Provide a small factory header (for example StatusProviders.h). Failures become ProviderState::Error with a detail message, never a crash.
Tests: unit tests for all pure mapping and formatting; integration tests (tests/integration/status) that start each real provider on this laptop (it has a battery), wait up to a few seconds for the first snapshot, print it with TEST_NOTE and assert plausibility (clock within 2 s of the system time, battery percent 0..100 when present, keyboard label not empty, network state no longer Initializing), and check that Stop() prevents further callbacks.
