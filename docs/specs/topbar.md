# Module specification: topbar (phase B)

Read `AGENTS.md` first; it states the rules every implementer follows. This is the work order that
was given to the implementing engineer. The real headers in the repository are authoritative where
they differ from names used here.

Module: topbar (directory src/topbar, target aether_topbar; deps aether_ui aether_accessibility aether_status aether_status_audio aether_weather aether_settings aether_graphics aether_platform aether_diagnostics aether_core user32 shell32).
Your files: src/topbar/**, tests/unit/topbar/**, tests/integration/topbar/**, docs/modules/topbar.md.
Read also: docs/decisions/0003-window-behavior.md, docs/knowledge/modules/TopBar.md, src/status/* (StatusTypes.h, providers, ClockFormatter), src/status/audio/*, src/weather/* (WeatherConditions), src/settings/*, src/ui/accessibility/*.
1. TopBarModel (pure): latest snapshots + TopBarSettings -> display items {id, kind Logo|Weather|Keyboard|Network|Volume|Microphone|Battery|Clock, text, glyph state, tooltip, accessible name, visible}. Hidden per settings; battery hidden when absent and hideBatteryWhenAbsent; weather only when enabled; unknown values shown as unknown ("Battery status unavailable"), never 0; Initializing shows a neutral placeholder without numbers; clock/date via ClockFormatter. Every state distinguishable without colour.
2. Layout (pure): bar height ~32 DIP; left: Aether logo button (original vector mark in the brand gradient, or resources/branding/png/aether-mark-*.png through BitmapCache when present); right: status items then date and time; token spacing; on narrow monitors hide low-priority items (weather, then keyboard); deterministic hit-testing.
3. TopBarWindow : ui::SurfaceWindow (topmost, noActivate, toolWindow): primary work area width minus 12 DIP side margins, at topMargin; glass panel (tokens.barCornerRadius, blur when available). AppBar when reserveSpace: SHAppBarMessage ABM_NEW with a callback message, ABM_QUERYPOS/ABM_SETPOS on the top edge (height = bar + topMargin + small gap), ABN_POSCHANGED re-queries, ABN_FULLSCREENAPP hides/shows and emits FullscreenChanged(bool) for the app to forward to the Dock, ABM_REMOVE on destroy; OnExplorerRestarted() re-registers; Relayout() on display/DPI/work-area changes.
4. Original vector glyphs, consistent 1.5 DIP strokes: Wi-Fi (bars only from real signalBars), Ethernet, no network, limited connectivity badge, speaker 0-3 waves and muted, microphone and muted, unavailable variants, battery outline filled to the real percent, charging bolt, AC plug without battery info, keyboard label text, weather glyphs (sun, moon, cloud, rain, snow, fog, thunder) + temperature, and a small marker for cached/offline weather.
5. Interactions: tooltips with details (connectivity, device names, battery time left when known, weather attribution "Weather data by Open-Meteo.com" and observation time); click volume -> ToggleMute (real API; error tooltip on failure); wheel on volume -> +/-2 % SetVolume; click microphone -> ToggleMute; click logo -> TrackPopupMenuEx (Search..., Settings..., Check for updates..., About Aether Shell, Quit Aether Shell) emitting signals; click clock -> tooltip with the long date. Accessibility via accessibility::AccessibleSurface (Button for logo/volume/mic, Text for others, names and status).
6. Render only on change: provider listeners post through IUiDispatcher then Invalidate(); subtle cross-fade on value changes (instant under reduced motion); no idle frames.
Public API: Create(context with GraphicsDevice&, FrameScheduler&, IUiDispatcher&, SettingsService&, provider pointers — any may be null when that provider failed), Show(), Relayout(), OnExplorerRestarted(), SetTheme(...); signals SearchRequested, SettingsRequested, CheckForUpdatesRequested, AboutRequested, QuitRequested, FullscreenChanged(bool).
Tests: unit tests for the model and layout (no battery, unknown values, offline/cached weather, narrow screens); integration test with fake snapshots over a test-pattern backdrop (reserveSpace=false — never register an AppBar or change the work area in tests), captures %TEMP%\AetherShellTests\topbar-{dark,light}.png with pixel checks; LOOK at them and polish until premium; one integration test with the REAL providers (read-only, no audio changes) for 3 s printing the item texts with TEST_NOTE.
