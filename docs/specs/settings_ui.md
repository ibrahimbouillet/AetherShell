# Module specification: settings_ui (phase B)

Read `AGENTS.md` first; it states the rules every implementer follows. This is the work order that
was given to the implementing engineer. The real headers in the repository are authoritative where
they differ from names used here.

Module: settings_ui (directory src/settings/ui, target aether_settings_ui; deps aether_ui aether_settings aether_updates aether_applications aether_weather aether_graphics aether_platform aether_diagnostics aether_core comctl32 shell32 user32 uxtheme ole32 windowscodecs).
Your files: src/settings/ui/**, tests/unit/settings_ui/**, tests/integration/settings_ui/**, docs/modules/settings_ui.md, USER_GUIDE.md (sections for what you implement; the lead completes the rest).
Standard Win32 controls (comctl32 v6) for accessibility, keyboard (expose PreTranslate(MSG&) using IsDialogMessage; the app registers it as a MessageLoop filter), IME, high contrast; Per-Monitor-V2 DPI with a small layout helper and the system message font for the DPI; dark title bar when apps are dark (platform::ApplyImmersiveDarkMode).
1. SettingsWindow (top-level, taskbar button, "Aether Shell Settings", single instance, brought to front when reopened). Navigation list: Dock, Top Bar, Weather, Updates, General, About.
 - Dock: icon size 32..96, bottom margin, icon spacing, opacity, hover magnification 1.0..2.0, show running apps, reserve screen space; pinned list with Move up/Move down/Remove and "Add application..." (chooser filtered by a search box over the catalog results provided by the app).
 - Top Bar: top margin, opacity, clock format (System/12 h/24 h), seconds, date style, show date, per-indicator visibility, hide battery when absent, reserve screen space.
 - Weather: enable with privacy note ("Weather requests are sent to Open-Meteo.com with the chosen coordinates"), location search via GeocodingClient on a worker thread (never the UI thread) -> results -> choose; unit; refresh interval; attribution "Weather data by Open-Meteo.com".
 - Updates: installed version (aether::build::kVersion), channel, automatic checks + interval, notifications, "Check now" (callback -> UpdateCoordinator::CheckNow) with live status from the coordinator snapshot; "View releases on GitHub" (open only https://github.com/ibrahimbouillet/AetherShell/... URLs).
 - General: Start with Windows (explicit consent text; StartupRegistration::Enable with the launcher path from the app; explain the Task-Manager-disabled state), motion (System/Reduced/Full), hotkeys enabled + their registration status (from the app), diagnostics: Open log folder; Export diagnostics... (logs + a system-info text without personal data into a folder the user picks; explain contents); Reset all settings... (confirmation, backup).
 - About: logo (resources/branding/png/aether-mark-128.png via WIC when present), "Aether Shell", version + source revision, "Created by Ibrahim Bouillet", "MIT License" with a View license dialog (standard MIT text with "Copyright (c) 2026 Ibrahim Bouillet"), project link, third-party notices summary.
 Changes apply live through SettingsService (debounce sliders ~150 ms); show validation warnings inline.
2. UpdateDialog: installed and available version, channel, publication date, download size, verification status, compatibility, release notes as PLAIN TEXT ONLY (read-only multiline EDIT with sanitized notes; never markup or clickable links from notes); buttons Download and install, Remind me later, Skip this version, Turn off update notifications, View release details (allow-listed https link); progress and errors; install disabled while busy.
Public API: SettingsWindow::Show(page), Close(), PreTranslate(MSG&); UpdateDialog::Show(snapshot), Update(snapshot), Close(); a callbacks struct injected by the app (checkForUpdates, downloadAndInstall, postpone, skip, disableNotifications, hotkeyStatus, launcherPath, catalog provider).
Tests: unit tests for pure helpers (DPI layout scaling, value<->control mapping, link allow-list, diagnostics export file selection); integration test with a temp SettingsService file: open the window, change controls via messages (TBM_SETPOS + WM_HSCROLL, BM_CLICK), verify the file changes, visit each page, capture ONLY the settings window (PrintWindow with PW_RENDERFULLCONTENT is fine) to %TEMP%\AetherShellTests\settings-*.png and LOOK to fix clipping/alignment/DPI. Never touch the real settings file or Run key.
