# Module specification: applications (phase A)

Read `AGENTS.md` first; it states the rules every implementer follows. This is the work order that
was given to the implementing engineer. The real headers in the repository are authoritative where
they differ from names used here.

Module: applications (directory src/applications, target aether_applications; deps: aether_core aether_diagnostics aether_platform shell32 ole32 oleaut32 propsys shlwapi user32 dwmapi, plus windowsapp only if you use WinRT).
Your files: src/applications/** EXCEPT src/applications/ApplicationTypes.h (contract owned by the lead; read it carefully; propose changes in followUps), tests/unit/applications/**, tests/integration/applications/**, docs/modules/applications.md.
1. ApplicationIdentity (pure functions): MakeIdForAumid, MakeIdForExecutable (full path, best-effort GetLongPathName, invariant lower case, backslashes), MakeIdForParsingName, IsPackagedAumid ("<PackageFamilyName>!<AppId>"), executable path validation (absolute, .exe, reject device paths such as \\.\ and \\?\GLOBALROOT, reject UNC by default).
2. ShellApplicationCatalog : IApplicationCatalog. Enumerate shell:AppsFolder (FOLDERID_AppsFolder) via SHGetKnownFolderItem and IShellItem::BindToHandler(BHID_EnumItems). For each IShellItem: display name (SIGDN_NORMALDISPLAY), parsing name (SIGDN_PARSINGNAME), PKEY_AppUserModel_ID, PKEY_Link_TargetParsingPath for desktop shortcuts (IShellItem2::GetString with documented PROPERTYKEYs from propkey.h). Packaged when the AUMID has the "!" package form or package properties exist; Desktop when the target is an .exe. Also walk the Start Menu Programs folders (FOLDERID_CommonPrograms, FOLDERID_Programs) .lnk files recursively (depth <= 6, <= 5000 files), resolving IShellLinkW targets with SLR_NO_UI and no SLR_UPDATE, to enrich executablePath and add missing entries. Skip uninstallers (names starting with "Uninstall", targets unins*.exe / uninstall*.exe), help files, URLs and documents (non-exe targets except packaged apps), and duplicates (merge by id; prefer entries that have both AUMID and exe). Respect cancellation. Runs on a COM STA (initialize a ComApartment inside when needed and document it). Log the discovery duration.
3. ShellApplicationLauncher : IApplicationLauncher. Launch on a dedicated STA WorkerPool: prefer the shell:AppsFolder item (SHCreateItemFromParsingName("shell:AppsFolder\" + parsingName) then ShellExecuteEx with SEE_MASK_IDLIST on the item's PIDL, SEE_MASK_FLAG_NO_UI, SW_SHOWNORMAL); else IApplicationActivationManager::ActivateApplication for AUMIDs; else ShellExecuteEx on the validated .lnk path; else on the validated executable path with its folder as working directory. NEVER build command lines from untrusted text; arguments only come from the trusted shortcut itself (launching the .lnk preserves them). Map failures (file not found, access denied, ERROR_CANCELLED from a declined UAC prompt) to Result errors with user-friendly messages. Completion through IUiDispatcher. Activate(): pick the most recent non-minimized window; restore minimized windows with ShowWindowAsync(SW_RESTORE); SetForegroundWindow; when the app is already in front, cycle to its next window; when SetForegroundWindow fails, FlashWindowEx and return ErrorCode::AccessDenied "Windows prevented activation". Never use AttachThreadInput tricks or synthesized keystrokes to bypass the foreground lock.
4. WindowTracker : IRunningApplicationTracker (UI thread). Initial EnumWindows, then SetWinEventHook for EVENT_OBJECT_SHOW, EVENT_OBJECT_HIDE, EVENT_OBJECT_DESTROY, EVENT_OBJECT_NAMECHANGE, EVENT_SYSTEM_FOREGROUND, EVENT_SYSTEM_MINIMIZESTART/END, EVENT_OBJECT_CLOAKED/UNCLOAKED (WINEVENT_OUTOFCONTEXT | WINEVENT_SKIPOWNPROCESS; filter idObject == OBJID_WINDOW and idChild == CHILDID_SELF). Coalesce bursts with a UI-thread timer (about 100 ms) and notify only on real changes. Eligibility predicate as a pure function over a WindowFacts struct (unit-testable): visible, not cloaked, top-level, unowned unless WS_EX_APPWINDOW, not WS_EX_TOOLWINDOW or WS_EX_NOACTIVATE unless WS_EX_APPWINDOW, non-empty title, not our own process, not shell windows (Progman, WorkerW, Shell_TrayWnd, Shell_SecondaryTrayWnd). Identity: per-window AUMID via SHGetPropertyStoreForWindow(PKEY_AppUserModel_ID); else the process via OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION) plus GetApplicationUserModelId (packaged) or QueryFullProcessImageNameW. For ApplicationFrameHost windows (class ApplicationFrameWindow) resolve the child CoreWindow's process to get the packaged app's AUMID. Processes that cannot be opened (protected or elevated): still listed with a "window:<class>" id and the title as name; document it. Group windows by id, track the foreground app, cache per-process lookups. Stop() unhooks and kills the timer.
5. ShellIconProvider : IIconProvider. One STA WorkerPool thread (shell extensions need STA). For each request create the shell item (AppsFolder parsing name, else .lnk, else exe), call IShellItemImageFactory::GetImage(size, SIIGBF_ICONONLY | SIIGBF_BIGGERSIZEOK), convert the HBITMAP to 32-bpp premultiplied top-down BGRA (detect bitmaps without alpha and set alpha 255; verify whether the returned DIB is already premultiplied and document it). LRU memory cache keyed by (key, size), limit about 256 entries; coalesce duplicate in-flight requests; CancelAll drops pending callbacks. Callbacks go through IUiDispatcher and never run after CancelAll or destruction.
Tests: unit tests for identity normalization, the eligibility predicate, dedup/merge rules and uninstaller filters. Integration tests on this machine: the catalog discovers more than 10 apps (TEST_NOTE the count and duration) including at least one Packaged and one Desktop entry; icon extraction returns a non-empty premultiplied image (every color component <= alpha) for 3 discovered apps; the tracker, run with a pumping message loop, lists existing windows (TEST_NOTE them) and excludes a top-level window created by the test process itself. Do NOT launch applications, activate windows or steal focus in automated tests.
