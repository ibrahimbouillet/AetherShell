# Module specification: dock (phase B)

Read `AGENTS.md` first; it states the rules every implementer follows. This is the work order that
was given to the implementing engineer. The real headers in the repository are authoritative where
they differ from names used here.

Module: dock (directory src/dock, target aether_dock; deps aether_ui aether_accessibility aether_applications aether_settings aether_graphics aether_platform aether_diagnostics aether_core user32 shell32).
Your files: src/dock/**, tests/unit/dock/**, tests/integration/dock/**, docs/modules/dock.md.
Read also: docs/decisions/0003-window-behavior.md, docs/knowledge/modules/Dock.md, src/applications/* (catalog, launcher, tracker, icon provider, identity), src/settings/* (Settings.h, SettingsService), src/ui/accessibility/*.
The Dock contains application icons ONLY (search entry, pinned, running). No clock, battery, network, volume or any status item.
1. DockModel (pure): item list = search entry first, pinned apps in settings order, then (if showRunningApps) running apps that are not pinned, separated visually; running state merged into pinned items by identity id (no duplicates); item {kind Search|Pinned|Running|Overflow, id, displayName, app info, running, foreground, windowCount}. Pin/unpin/move operations returning new pinned lists (PinnedApp from ApplicationInfo or RunningApplication). Overflow: shrink icons down to 32 DIP to fit the work-area width minus side margins; if still too wide, collapse trailing unpinned running apps into an Overflow item that opens a menu.
2. DockLayout (pure): positions in DIPs; panel rect; window size including headroom above the panel for magnification and shadow margins. Magnification: scale = 1 + (magnification-1) * smooth cosine falloff of the pointer distance (radius about 2.5 icon widths); icons grow upwards from a common baseline; neighbours shift so nothing ever overlaps and the panel widens smoothly; hit-testing uses the current animated geometry so the item under the pointer is the drawn one. Unit-test no-overlap for many pointer positions, symmetry, scale 1 when magnification is 1.0 or the pointer is outside, stable hit-testing.
3. DockWindow : ui::SurfaceWindow (topmost, noActivate, toolWindow), centred at the bottom of the primary monitor work area at bottomMargin; Relayout() on display/DPI/work-area changes; input region = panel (+ magnified icons while hovered). Rendering: graphics::PaintGlassPanel with backdrop blur when available; icons via IIconProvider at the right pixel size for DPI x max magnification, cached in graphics::BitmapCache; graphics::PaintFallbackIcon while loading or on failure; a crisp original vector search glyph for the search item; running indicator dot (accent for the foreground app); per-item graphics::Spring for magnification (interruptible, frame-rate independent); press feedback; launch bounce (skipped under reduced motion); ui::TooltipWindow with app names after tokens.tooltipDelay; focus ring in keyboard mode. No frames at idle.
4. Interactions: click search -> SearchRequested signal; not running -> IApplicationLauncher::LaunchAsync (errors shown as a short error tooltip near the icon, never a modal dialog); running -> Activate (cycles windows). Right click / Shift+F10 / Menu key -> TrackPopupMenuEx (Open, New window/instance for desktop apps, Pin to Dock / Unpin from Dock, Move left, Move right, Dock settings...). Drag-to-reorder pinned items (6 DIP threshold, animated, persisted through SettingsService). Middle click = new instance. Keyboard mode via FocusDock() (the app calls it from the Ctrl+Alt+D hotkey): Left/Right/Home/End, Enter/Space, Shift+F10/Menu, Escape returns focus to the previous window.
5. Full-screen: SetSuppressed(bool) hides/shows. Optional reserveSpace: bottom-edge AppBar helper (ABM_NEW/QUERYPOS/SETPOS/REMOVE) and OnExplorerRestarted() re-registers.
6. Accessibility: accessibility::AccessibleSurface — root ToolBar "Aether Shell Dock", items Button with names and status ("Running", "Pinned"), Invoke = click, focus events in keyboard mode, structure-changed on model changes.
7. SetTheme(tokens, motion, DockSettings) applies live.
Public API for the app: Create(context with GraphicsDevice&, FrameScheduler&, IUiDispatcher&, IApplicationLauncher&, IIconProvider&, SettingsService&), Show(), FocusDock(), SetRunningApplications(vector<RunningApplication>), SetSuppressed(bool), Relayout(), OnExplorerRestarted(), SetTheme(...); signals SearchRequested, SettingsRequested.
Tests: unit tests for DockModel and DockLayout; integration test creating the real DockWindow with fake launcher/icon provider/running apps over a test-pattern backdrop, capturing %TEMP%\AetherShellTests\dock-*.png at rest and while hovered (SendMessage WM_MOUSEMOVE to the dock window — never move the real cursor), pixel checks for icons and indicators and that hover enlarges the hovered icon; LOOK at the PNGs and polish until premium. Use a temp settings file.
