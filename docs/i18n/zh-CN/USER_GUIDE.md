# 使用 Aether Shell

从开始菜单快捷方式或已安装的启动器启动 Aether Shell。它会打开两个桌面元素：底部的程序坞和顶部的状态栏。Windows
资源管理器照常运行。程序坞中的项目带有快捷菜单。选择顶部栏的徽标可打开其菜单，其中也提供“设置”和“退出”。

从程序坞或按 Ctrl+Alt+空格 打开搜索。输入应用名称，用上/下方向键选择，按 Enter 打开。按 Esc 或使用其他任何东西都会
关闭搜索窗口，每次打开都从空白开始。设备管理器等 Windows 自带工具也能找到。只能启动已发现的应用；输入的文字永远
不会被当作命令执行。Ctrl+Alt+D 会将焦点移到程序坞。两个快捷键都可在“设置 → 常规”中修改，冲突也会在那里提示。

程序坞会区分已固定的应用和其他正在运行的应用。使用其快捷菜单或“设置 → 程序坞”可以固定、取消固定或重新排列项目，
并调整大小、放大效果和动效。正在运行的应用可以从其程序坞项目中激活。部分 UWP 窗口的归属仍需验证。Alpha 3：将指针
悬停在正在运行的应用上时，其标记会变宽，稍候片刻会显示一张包含其窗口预览的卡片。单击某个预览可切换到该窗口，单击
其关闭按钮则会请求该窗口正常关闭；是否关闭由应用决定（例如先询问是否保存）。

顶部栏显示来自已公开 Windows API 的状态。未知的状态始终显示为未知。没有电池的台式电脑可以隐藏电池项目。不支持
“麦克风正在使用”指示；设备可用性和静音是另外的信息。只有在你确实想更改输出音量或静音时，才单击可用的音频控件。
顶部栏从不显示网络名称。自 3.3 起：在快捷控制中，WLAN 磁贴上的箭头会列出你周围的网络及其信号。选择一个即可加入；
如果需要密码，Aether 会询问，由 Windows 保存。名称和密码绝不会被记录或发送。Alpha 2 增加了通过键盘项目用
Win+空格 切换输入语言，以及通过天气项目打开天气设置。网络/音频/电池组合按钮会打开 Aether 的快捷控制，其中包括
Windows 提供活动会话时的媒体控制、音量、受支持的亮度和系统操作磁贴。不受支持的开关会打开相应的 Windows 控件，
而不会假装更改了设备。在真实设备上的验证仍然有限。单击麦克风会切换其静音；其右键菜单提供隐私设置和
**启动 Windows 语音输入（Win+H）**。语音操作会先把焦点交还给之前的应用，然后请 Windows 在其活动字段中打开听写。
听写是否可用、麦克风权限和处理过程均由 Windows 控制；Aether Shell 不会采集或存储语音。自动化测试不会调用真实的听写。

Alpha 3 为顶部栏增加了三个入口。单击日期和时间可打开 Windows 通知中心（Windows 11 上为 Win+N，Windows 10 上为
Win+A）；其菜单也能打开日历。Aether 从不读取、清除或统计你的通知。小箭头会在正下方打开 Windows 通知区域中的隐藏
图标；打开时箭头朝上，再次单击即可关闭。可在“设置 → 顶部栏 → **显示隐藏图标按钮**”中隐藏此箭头。网络/音频/电池
组合按钮会打开 Aether 的快捷设置面板，包含第二页以及 WLAN、蓝牙、辅助功能和声音输出的详细视图；Windows 不对外开放
的开关会打开相应的 Windows 设置页面。在 Windows 11 上，同一页面中的 **使用 Windows 快速设置（Windows 11）** 会改为
打开 Windows 自带的面板。

**语言**（Alpha 4）：Aether Shell（包括安装程序）支持英语、中文（简体）、印地语、西班牙语、法语、葡萄牙语、俄语、阿拉伯语、
孟加拉语和乌尔都语。在“设置 → **语言**”中选择其一；默认的**跟随 Windows** 会按你排列的顺序查看你的 Windows 显示语言，并
使用其中第一个属于这十种语言的语言，否则使用英语。更改会立即应用到顶部栏、程序坞、菜单、搜索和设置，你的选择会保存在每个
版本都会读取的设置中：新版本、修复或重新安装都会再次找到它，安装程序、更新程序和启动器也会使用这种语言。选择了某种语言后，
顶部栏会用该语言显示日期；选择“跟随 Windows”时，日期保持你的 Windows 区域格式。应用、文件和网络的名称永远不会被翻译。搜索
会用界面语言显示 Windows 工具和设置页面，并能通过十种语言中任意一种的名称找到它们。阿拉伯语和乌尔都语从右向左阅读。

设置包含“程序坞”“顶部栏”“天气”“更新”“常规”“关于”“桌面”“外观”“欢迎”和“语言”页面。天气默认关闭。启用前，请在征得
同意后选择 Windows 自动定位，或手动选择位置。Windows 可能拒绝定位，此时不会凭空生成位置或天气。手动搜索地点会把
输入的地名发送给 Open-Meteo；天气预报会发送所选的大致坐标。位置永远不会根据 WLAN 名称或原始 IP 推断。缓存的预报
会在六小时后消失。数据来源：Open-Meteo.com，CC BY 4.0。

**天气窗口**（Alpha 4）：点击 Top Bar 中的天气（右键菜单仍保留“**天气设置…**”），或打开“设置”→“天气”→
“**打开天气**”。窗口显示地点、当地时间和对应时段的天空、温度和体感温度、未来 24 小时、7 天、太阳轨迹、湿度、风、
紫外线和气压，以及该国家/地区的地图和当前各地气温。可以搜索其他城市，或选择“**我的位置**”；如果尚未允许定位，
窗口会向 Windows 请求，或打开 Windows 的定位设置。“**精确位置**”（默认开启）使用 Windows 提供的约 100 米精度的
位置；关闭后取整到约 10 公里。Top Bar 的天气图标只在指针停留时才会动。地图来自 Natural Earth（公共领域），存储在
应用程序中。在“外观”中选择 **Liquid** 时，天气窗口、快速设置、搜索、菜单和 Dock 预览都和栏一样是玻璃效果，
“设置”也采用 Liquid 外观；选择 **Grain** 时，全部为磨砂颗粒效果。

“常规”包含启动许可、动效偏好和快捷键编辑。全新的交互式安装（自 Alpha 2 起）会明确勾选登录时启动；如不需要，请在
安装前取消勾选。已有的选择会被保留。静默安装需要显式的启动参数。启动按用户设置且可选；“设置 → 常规 → 应用”可以
更改它，任务管理器也可以单独将其禁用。登录后的启动顺序和延迟由 Windows 控制；它可能会在 Aether 就绪之前先显示原生
桌面和任务栏。已安装的稳定启动器会在异常崩溃后有限次数地重试。主动退出、更新、卸载或普通错误都会使其停止；没有任何
进程能保证在所有故障中都继续运行。高对比度和减少动效会尽可能跟随 Windows。“关于”页面包含 MIT 许可证和项目署名。

在 V2 版本中，“桌面”页面包含默认开启的 **替换 Windows 任务栏**（D23）。已保存的明确关闭选择会被保留。取消勾选并
单击“应用”即可恢复共存；勾选并单击“应用”即可再次启用替换。关闭窗口或切换页面会丢弃尚未应用的更改。在替换模式下，
程序坞会在最大化的应用下方保留空间。手动放置的普通窗口可能仍需移动。状态消息会显示替换是否已生效或不可用。Windows
设置保留其原生的任务栏页面；请在这里更改 Aether Shell 的行为。在 Alpha 3 的替换模式下，符合条件的最大化窗口会获得
圆角和细边框，但不会改变其大小或最大化状态；Aether 退出时会撤销这些更改。部分应用和窗口类型保持直角。自 3.3 起，
仅在两条栏之间如此。两条栏都隐藏时，最大化窗口会占满整个屏幕，保持直角。

自 Alpha 4 起（D72）：两条栏之间的每个最大化窗口都有圆角，不论是哪种应用（浏览器、文件资源管理器、打包应用或以管理员身份运行的应用），
并保留自己的标题栏按钮。Aether 不再改动应用的窗口：它把自己的小块放在四个角上，实时显示那里的桌面，四周是细边框。圆角没有抗锯齿。
位于最大化窗口前面的窗口会像遮住其他内容一样遮住它们。

**顶部栏显示为桌面上的文字**（Alpha 4，D71）：设置 → 顶部栏 → **呈现方式** → **桌面上的文字** 会去掉栏本身。相同的项目直接写在屏幕最顶部的
桌面壁纸上，根据下方的图片选用浅色或深色文字，并带有柔和的光晕。这一条区域不会被窗口占用；顶部边距和玻璃不透明度不适用。启用
**自动隐藏顶部栏** 时，只要下方有窗口，文字就会回到一条玻璃带上。高对比度模式保留栏。

**欢迎问候**（自 3.3 起）：登录或解锁后，Aether Shell 会在模糊的桌面壁纸上手写一段铺满屏幕的简短问候，结束后两条栏
随之出现：“Salut”“Hello”或“Hola”，如果你填写了名字，还会加上你的名字。解锁时，它已在原本桌面的位置等候。触摸、
单击或按 Esc 即可跳过。安装程序会询问名字（可选，自 3.5 起）；“设置 → 欢迎”可以关闭它，并设置语言和名字。如果壁纸
文件被移动或删除，欢迎问候会使用 Windows 保存的副本。名字和你的壁纸都只保存在这台电脑上，绝不会被发送或记录，清空
字段即可删除名字。它只会在 Windows 完成登录后出现；Windows 登录界面本身不会改变。登录时，它会在 Windows 启动 Aether
后立即出现，这可能晚于桌面出现。

**触控**（自 3.3 起）：用手指拖动任意长列表或页面；它会紧跟手指，松开后继续滑动，越过两端时会柔和地回弹。轻触在抬起
手指时生效，拖动永远不会触发操作，在顶部栏或程序坞中长按项目会打开其菜单（长按并移动可重新排列程序坞）。从屏幕顶部或
底部边缘向内轻扫，可以唤回隐藏的栏。在快捷设置中，上下拖动可在页面之间切换。在滑块上左右移动可调整数值，或直接轻触
目标位置；在滑块上上下拖动则会滚动页面。设置中的滑块会在松开时生效。

**自动隐藏**（Alpha 3）可分别为两条栏设置：“设置 → 程序坞 → **自动隐藏程序坞**”和“设置 → 顶部栏 → **自动隐藏顶部
栏**”。两者默认关闭。自动隐藏的栏会在应用窗口遮住它时滑开。将指针停在屏幕底部边缘即可唤回程序坞；停在屏幕最顶端
（没有边距）四分之一秒即可唤回顶部栏；提前移开则会取消，因此应用的标签页和关闭按钮不受影响。在你使用它、或其菜单
或面板打开时，它会保持显示，之后不久再次隐藏。在桌面上，即使背后有窗口（显示桌面），两条栏也会回来。自动隐藏的栏
不会保留屏幕空间，因此最大化窗口会占满屏幕，唤回的栏显示在其上方，就像 Windows 自带的自动隐藏任务栏。

“桌面”页面还提供“导入 Windows 任务栏固定项”。它会读取受支持的已固定快捷方式并添加缺少的项目，不会更改 Windows 的
固定项，也不会替换你在 Aether 中的固定项。部分 Windows 11 固定项及其原始顺序无法读取。替换模式会导入受支持的固定项，
并添加一次文件资源管理器。自动同步会在启动、开启同步或资源管理器重启时添加新的可用固定项；它会保留你的排列顺序和
明确的移除操作。手动导入可以恢复已移除的固定项。“外观”页面包含自动同步开关、主题与强调色、图标预设和动效设置。

程序坞包含“开始”“搜索”和“任务视图”项目。拖动已固定的图标可更改其保存的顺序；拖动仅在运行的图标只会更改本次会话
中的顺序，而不会固定它。如果存在按窗口提供的配置文件图标元数据，就能区分 Chrome 的不同配置文件；没有时图标保持通用。
程序坞的快捷菜单会提供适用的窗口、新实例和固定操作，而不会猜测配置文件。

顶部栏菜单可打开时钟、电源、声音和网络设置。原本显示原生任务栏的末尾箭头已在 Alpha 2 中移除；自 Alpha 3 起，隐藏
图标箭头可打开 Windows 通知区域的溢出菜单。恢复功能仍可通过“桌面”设置、“退出”和独立的恢复命令使用。兼容性暂停/
恢复路径仍为内部功能。

要恢复原生任务栏，请关闭“桌面”中的选项，或在顶部栏菜单中选择“退出”。

在安装文件夹中，`AetherShell.exe --restore-taskbar` 会请求正在运行的实例关闭此模式。当 Aether Shell 未运行时，同一
命令会自行恢复 Windows 任务栏：
- 使用任务栏被隐藏前保存的状态；
- 关闭此模式；
- 显示结果。

`AetherShell.exe --quit` 会请求正在运行的实例退出；如果没有运行的实例，则不执行任何操作。

独立的恢复助手会在应用故障后恢复任务栏；如果恢复助手退出，应用也会这样做。在“Windows 设置 > 应用 > 已安装的应用”
中执行**修复**或**卸载**，也能恢复被 Aether Shell 隐藏的任务栏。修复会保留你的设置，包括“桌面”中的选择，因此除非
你关闭该选项，否则 Aether Shell 下次启动时会再次隐藏任务栏。如果以上方法都无效，请在任务管理器中结束 Aether Shell
的进程并重新启动 Windows 资源管理器。在所有故障情况和所有 Windows 版本上的恢复尚未经过验证；启用此模式前请阅读已知
限制。

本地数据位于 `%LOCALAPPDATA%\AetherShell`：设置、缓存、更新和大小受限的日志。可从“常规”页面打开日志文件夹。基本
诊断导出只包含产品版本和 Windows 版本号；分享任何文件之前请自行检查。恢复默认设置会先请求确认，并保留设置备份。
卸载会保留用户数据，除非你明确选择删除。

目前尚未验证的内容，请参见[已知限制](../../../KNOWN_LIMITATIONS.md)（英文）。
