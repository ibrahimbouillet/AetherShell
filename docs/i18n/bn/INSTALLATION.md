# ইনস্টলেশন

শুধু [অফিসিয়াল রিপোজিটরির রিলিজ পেজ](https://github.com/ibrahimbouillet/AetherShell/releases) থেকে সেটআপ এক্সিকিউটেবল ব্যবহার করুন।
বর্তমান রিলিজ, Alpha 4 [0.4.0-alpha.4](https://github.com/ibrahimbouillet/AetherShell/releases/tag/v0.4.0-alpha.4), ম্যানুয়াল-ইনস্টলের
একটি প্রিভিউ; সংস্করণ 1-এর বিস্তৃত যাচাই এখনো বাকি। আগের
[0.2.0-alpha.2](https://github.com/ibrahimbouillet/AetherShell/releases/tag/v0.2.0-alpha.2) এখনো উপলব্ধ।

আপনার সাধারণ Windows ব্যবহারকারী হিসেবে সেটআপ চালান। Alpha 4 থেকে সেটআপ সেই ভাষায় কথা বলে যা আপনি Aether Shell-এর সেটিংসে বেছে
নিয়েছেন, তা না থাকলে আপনার Windows ডিসপ্লে ভাষায় (ইন্টারফেসের 41টি ভাষার যেকোনোটি হলে), নইলে ইংরেজিতে। ইনস্টলের পর
সেটআপ আপনার Windows-এ থাকা ইন্টারফেস ভাষাগুলো রিলিজ থেকে ডাউনলোড করে (প্রতিটি কয়েক দশ KB); অফলাইনে থাকলে Aether Shell
চালু হওয়ার সময় সেগুলো ডাউনলোড করে। উইজার্ড পণ্যটি ব্যাখ্যা করে, MIT লাইসেন্স দেখায় এবং আপনাকে একটি ফোল্ডার (ডিফল্ট `%LOCALAPPDATA%\Programs\AetherShell`), শর্টকাট ও ঐচ্ছিক
স্টার্টআপ বেছে নিতে দেয়। এটি একটি স্থিতিশীল লঞ্চার, একটি রক্ষণাবেক্ষণ সেটআপ এবং সংস্করণ-ভিত্তিক প্রোগ্রাম ফাইল ইনস্টল করে। এটি
স্টার্ট মেনুতে একটি শর্টকাট এবং Windows-এর ইনস্টল করা অ্যাপে প্রতি-ব্যবহারকারী একটি এন্ট্রি তৈরি করতে পারে। কোনো অ্যাডমিনিস্ট্রেটর
অধিকার বা এক্সপ্লোরার প্রতিস্থাপন ব্যবহার করা হয় না। নতুন ইন্টারঅ্যাকটিভ ইনস্টলেশনে (Alpha 2 থেকে) **সাইন-ইনে চালু করুন**
স্পষ্টভাবে বাছাই করা থাকে: না চাইলে ইনস্টলের আগে এটি অচিহ্নিত করুন। সেটআপ মেনে নিলে সেই পছন্দ সংরক্ষিত হয়; আগে সংরক্ষিত পছন্দ ও
টাস্ক ম্যানেজারে বন্ধ করা অবস্থা মানা হয়। সাইলেন্ট সেটআপ শুধু স্পষ্ট `--start-with-windows` ফ্ল্যাগ থাকলেই স্টার্টআপ চালু করে;
`--no-start-with-windows` বন্ধ বেছে নেয়। পোর্টেবল প্রোফাইল সম্মতি না দেওয়া পর্যন্ত বন্ধ থাকে। সাইন-ইনে চালুর ক্রম Windows
নিয়ন্ত্রণ করে এবং দেরি করাতে পারে।

V2 শেল Aether Shell চালু হলে ডিফল্টে দৃশ্যত Windows টাস্কবার প্রতিস্থাপন করে। সেটআপ এই আচরণ জানিয়ে দেয়; অ্যাপটি একটি পুনরুদ্ধার
সহায়ক এবং **সেটিংস → ডেস্কটপে** বন্ধ করার বিকল্প রাখে। স্বাভাবিকভাবে বের হলে Windows টাস্কবার ফিরে আসে। এক্সপ্লোরার চলতে থাকে, আর
Windows সেটিংস Aether Shell নয়, Windows-কেই কনফিগার করে। পুনরুদ্ধারের সীমাবদ্ধতা ও জরুরি কমান্ড আছে
[ব্যবহারকারী নির্দেশিকায়](USER_GUIDE.md)।

স্বাক্ষরহীন অ্যাপ্লিকেশন/সেটআপ বাইনারি SmartScreen চালু করতে পারে। এই আলফার কোনো Authenticode প্রকাশক সার্টিফিকেট নেই। চালানোর
সিদ্ধান্ত নেওয়ার আগে রিলিজের সঠিক উৎস ও SHA-256 যাচাই করুন:

```powershell
Get-FileHash .\AetherShell-0.4.0-alpha.4-win-x64-setup.exe -Algorithm SHA256
```

সংশ্লিষ্ট চেকসাম ফাইলের সাথে মেলান। শুধু চেকসাম দিয়ে প্রকাশকের পরিচয় প্রমাণ হয় না। স্বয়ংক্রিয় আপডেটের জন্য অতিরিক্তভাবে
[UPDATE_AND_ROLLBACK](../../../UPDATE_AND_ROLLBACK.md) (ইংরেজিতে)-এ বর্ণিত স্বাক্ষরিত রিলিজ ম্যানিফেস্ট লাগে।

সক্রিয় সংস্করণকে এর মিলে যাওয়া সেটআপ দিয়ে মেরামত করতে ইনস্টল করা অ্যাপ → Aether Shell → পরিবর্তন ব্যবহার করুন। আনইনস্টল
অ্যাপকে স্বাভাবিকভাবে বন্ধ হতে বলে এবং শুধু ইনস্টলেশনের নিবন্ধিত এন্ট্রি ও ফাইল সরায়। ব্যবহারকারীর ডেটা রাখা ডিফল্ট; সেটিংস/ক্যাশ/লগ
মুছতে স্পষ্টভাবে অপসারণ বেছে নিন। স্পষ্টভাবে ডাউনগ্রেডের অনুমতি না দিলে পুরোনো সেটআপ প্রত্যাখ্যাত হয়। যেকোনো ইচ্ছাকৃত ডাউনগ্রেডের
আগে ব্যবহারকারীর ডেটার একটি ব্যাকআপ রাখুন।

নিচের সাইলেন্ট কমান্ডগুলো ইনস্টলেশন ফোল্ডারের ভেতরের রক্ষণাবেক্ষণ এক্সিকিউটেবল ব্যবহার করে; ডাউনলোড করা সেটআপ ফাইলের নামে সংস্করণ
ও আর্কিটেকচার থাকে। পূর্ণ (absolute) কাস্টম পাথ ব্যবহার করুন:

```powershell
.\AetherShellSetup.exe --silent --no-launch
.\AetherShellSetup.exe --silent --repair --no-launch
.\AetherShellSetup.exe --silent --uninstall --keep-user-data
```

বিকল্প: `--install-root <ফোল্ডার>`, `--data-dir <ফোল্ডার>`, `--no-shortcuts`, `--no-launch`,
`--start-with-windows` (স্পষ্ট সম্মতি), `--repair`, `--uninstall`, `--keep-user-data`,
`--no-start-with-windows` (স্পষ্ট অস্বীকৃতি),
`--remove-user-data`, `--allow-downgrade`, `--log <ফাইল>`। সাইলেন্ট মোড কখনো কিছু জিজ্ঞেস করে না। এক্সিট কোড: 0 সফল, 1 কাজ ব্যর্থ,
2 অবৈধ আর্গুমেন্ট/পাথ সেটআপ ব্যর্থ। সাধারণ GUI চলমান কাজের সময় বন্ধ হতে দেয় না; বাতিল ও স্ব-আনইনস্টলের যাচাই
[KNOWN_LIMITATIONS](../../../KNOWN_LIMITATIONS.md) (ইংরেজিতে)-এ অনুসরণ করা হয়।
