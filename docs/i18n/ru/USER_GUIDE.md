Запустите Aether Shell с помощью ярлыка в меню «Пуск» или установленного загрузчика. Он открывает два элемента рабочего
стола: Dock у нижнего края и верхнюю панель состояния у верхнего. Проводник Windows продолжает работать как обычно. У
элементов Dock есть контекстные меню. Выберите логотип верхней панели, чтобы открыть её меню, в котором также есть
«Параметры» и «Выйти».

Откройте поиск из Dock или сочетанием Ctrl+Alt+Пробел. Введите название приложения, выберите его клавишами Вверх/Вниз и
нажмите Enter, чтобы открыть. Esc закрывает окно поиска, как и любое другое действие, а каждое открытие начинается с
пустой строки. Находятся и собственные средства Windows, например диспетчер устройств. Запускать можно только найденные
записи приложений; введённый текст никогда не является командой оболочки. Ctrl+Alt+D переводит фокус на Dock. Оба
сочетания настраиваются в «Параметры → Общие»; конфликты сообщаются там же.

Dock отличает закреплённые приложения от остальных запущенных. Используйте его контекстное меню или «Параметры → Dock»,
чтобы закреплять, откреплять и переупорядочивать записи, а также настраивать размер, увеличение и анимацию. Запущенное
приложение можно активировать с его элемента в Dock. Привязка некоторых окон UWP всё ещё требует проверки. Alpha 3:
наведение на запущенное приложение расширяет его маркер и после короткой паузы показывает карточку с миниатюрами его
окон. Щёлкните миниатюру, чтобы перейти к этому окну, или её кнопку закрытия, чтобы попросить закрыться именно это окно в
обычном порядке; закрываться ли, решает приложение (например, после вопроса о сохранении).

Верхняя панель показывает снимки данных из документированных API Windows. Неизвестное состояние остаётся неизвестным.
Настольный ПК без батареи может скрывать значок батареи. Индикатор «микрофон используется» не поддерживается; сведения о
доступности и отключении звука устройства — отдельные. Нажимайте доступные элементы управления звуком, чтобы изменить
громкость вывода или отключить звук, только когда вы этого хотите. Верхняя панель никогда не показывает название сети.
Начиная с 3.3: в быстрых параметрах стрелка на плитке Wi-Fi показывает список сетей вокруг вас с уровнем сигнала.
Выберите сеть, чтобы подключиться; Aether запросит пароль, если он нужен, а хранит его Windows. Названия и пароли никогда
не записываются в журнал и не отправляются. Alpha 2 добавляет переключение языка ввода по Win+Пробел с элемента
клавиатуры и параметры погоды с видимого элемента погоды. Сгруппированное действие сети/звука/батареи открывает быстрые
элементы управления Aether, включая управление воспроизведением, когда Windows предоставляет активный сеанс, громкость,
поддерживаемую яркость и плитки системных действий. Переключатели, которые устройство не поддерживает, открывают
соответствующие элементы управления Windows, а не делают вид, что меняют устройство. Проверка на реальных устройствах
остаётся ограниченной. Щелчок по микрофону отключает или включает конечное устройство; меню правой кнопки предлагает
параметры конфиденциальности и **Запустить голосовой ввод Windows (Win+H)**. Голосовое действие возвращает фокус
предыдущему приложению, прежде чем попросить Windows открыть диктовку в его активном поле. Доступностью диктовки,
разрешением на микрофон и обработкой занимается Windows; Aether Shell не записывает и не хранит речь. Автоматические
тесты не вызывают настоящую диктовку.

Alpha 3 добавляет три точки входа в верхнюю панель. Щёлкните дату и время, чтобы открыть центр уведомлений Windows
(Win+N в Windows 11, Win+A в Windows 10); его меню также открывает календарь. Aether никогда не читает, не очищает и не
подсчитывает ваши уведомления. Небольшая стрелка открывает прямо под собой скрытые значки области уведомлений самой
Windows; пока они открыты, стрелка смотрит вверх, а второй щелчок закрывает их. Скройте стрелку в «Параметры → Верхняя
панель → **Показывать кнопку скрытых значков**». Сгруппированное действие сети/звука/батареи открывает панель быстрых
параметров Aether со второй страницей и подробными видами для Wi-Fi, Bluetooth, специальных возможностей и вывода звука;
переключатели, которые Windows оставляет себе, открывают соответствующую страницу параметров Windows. В Windows 11
пункт **Использовать быстрые параметры Windows (Windows 11)** на той же странице открывает вместо них собственную панель
Windows.

**Язык** (Alpha 4): Aether Shell, включая программу установки, говорит на английском, китайском (упрощённом), хинди,
испанском, французском, португальском, русском, арабском, бенгальском и урду. «Параметры → **Язык**» выбирает один из них;
вариант **«Как в Windows»**, по умолчанию, просматривает языки интерфейса вашей Windows в том порядке, в котором вы их
расположили, и берёт первый из десяти, а если такого нет — английский. Изменение сразу применяется к панелям, меню,
поиску и параметрам, а ваш выбор хранится в ваших параметрах, которые читает каждая версия: новая версия, ремонт или
переустановка находят его снова, и программа установки, программа обновления и загрузчик говорят на этом языке. При
выбранном языке верхняя панель пишет дату на нём; при варианте «Как в Windows» дата сохраняет региональный формат
Windows. Названия приложений, файлов и сетей никогда не переводятся. Поиск показывает средства и страницы параметров
Windows на языке интерфейса и находит их по названию на любом из десяти языков. Арабский и урду читаются справа налево.

В параметрах есть страницы Dock, Верхняя панель, Погода, Обновления, Общие, О программе, Рабочий стол, Оформление,
Приветствие и Язык. Погода по умолчанию выключена. Перед её включением выберите автоматическое определение расположения
Windows с вашего согласия или ручной выбор места. Windows может отказать в доступе к расположению — тогда никакое
расположение и никакая погода не выдумываются. Ручной поиск места отправляет введённое название в Open-Meteo; прогнозы
отправляют выбранные приблизительные координаты. Расположение не определяется по названию сети Wi-Fi или по «сырому»
IP-адресу. Кэшированные прогнозы исчезают через шесть часов. Источник данных: Open-Meteo.com, CC BY 4.0.

**Окно погоды** (Alpha 4): щёлкните погоду в Top Bar (в её меню правой кнопки остаётся **«Параметры погоды…»**) или
откройте «Параметры» → «Погода» → **«Открыть погоду»**. В окне показаны место, его местное время и небо этого часа,
температура и ощущаемая температура, следующие 24 часа, 7 дней, дуга солнца, влажность, ветер, УФ-индекс и давление, а
также карта страны с текущими температурами. Найдите другой город или выберите **«Моё расположение»**; если доступ к
расположению ещё не разрешён, окно запросит его у Windows или откроет параметры расположения Windows. **«Точное
расположение»** (включено по умолчанию) использует положение Windows с точностью около 100 м; если его выключить, оно
округляется примерно до 10 км. Значок погоды в Top Bar движется, только пока над ним указатель. Карта взята из Natural
Earth (общественное достояние) и хранится в приложении. Если в «Оформлении» выбран **Liquid**, окно погоды, быстрые
настройки, поиск, меню и превью Dock сделаны из стекла, как панели, а «Параметры» получают облик Liquid; с **Grain**
всё зернистое.

В «Общие» находятся согласие на автозапуск, параметры анимации и редактирование сочетаний клавиш. Новая интерактивная
установка (начиная с Alpha 2) явно выбирает автозапуск при входе; чтобы отказаться, снимите этот флажок перед установкой.
Имеющиеся выборы сохраняются. Для тихой установки нужен явный флаг автозапуска. Автозапуск относится к пользователю и
необязателен; изменить его можно в «Параметры → Общие → Применить», а диспетчер задач может независимо его отключить.
Порядок и задержку запуска после входа определяет Windows; она может показать нативный рабочий стол и панель задач
раньше, чем Aether будет готов. Установленный стабильный загрузчик повторяет запуск ограниченное число раз после
аварийных исключений Windows. Намеренный выход, обновление или удаление и обычные ошибки его останавливают; никакой
процесс нельзя гарантированно сохранить работающим при любых сбоях. Высокая контрастность и уменьшенная анимация следуют
Windows там, где это поддерживается. Страница «О программе» содержит лицензию MIT и сведения об авторстве проекта.

В кандидате V2 в «Рабочий стол» есть пункт **Заменить панель задач Windows**, включённый по умолчанию (D23). Явный
сохранённый отказ сохраняется. Снимите флажок и нажмите «Применить», чтобы вернуть сосуществование; установите его и
нажмите «Применить», чтобы снова включить замену. Закрытие или переход на другую страницу отменяет неприменённое
изменение. В режиме замены Dock резервирует место под развёрнутыми приложениями. Обычные окна, расставленные вручную,
всё же могут потребовать перемещения. Сообщение о состоянии показывает, активна ли замена или недоступна. В параметрах
Windows остаётся нативная страница панели задач; поведение Aether Shell меняйте здесь. В режиме замены Alpha 3
подходящие развёрнутые окна получают скруглённые углы и тонкую кайму без изменения размера и состояния развёрнутости;
при выходе Aether отменяет это. Некоторые приложения и типы окон сохраняют прямые углы. Начиная с 3.3 — только между
панелями. Когда обе панели скрыты, развёрнутое окно занимает весь экран с прямыми углами.

Начиная с Alpha 4 (D72): любое развёрнутое окно между панелями получает скруглённые углы, каким бы ни было приложение
(браузеры, проводник, упакованные и запущенные с повышенными правами приложения) и сохраняет собственные кнопки заголовка.
Aether больше вообще не трогает окно приложения: небольшие собственные фрагменты, расположенные над четырьмя углами,
показывают лежащий там рабочий стол в реальном времени, а вокруг идёт тонкая кайма. Углы не сглажены. Окно перед
развёрнутым закрывает их, как закрывало бы что угодно другое.

**Верхняя панель в виде текста на рабочем столе** (Alpha 4, D71): «Параметры → Верхняя панель → **Вид** → **Текст на
рабочем столе**» убирает саму панель. Те же элементы пишутся у самого верха экрана прямо поверх картинки рабочего стола
светлыми или тёмными чернилами, выбранными по картинке под ними, с мягким ореолом. Эта полоса остаётся свободной от окон;
верхний отступ и непрозрачность стекла не применяются. При включённом **Автоматически скрывать верхнюю панель** текст
возвращается на полосе стекла, пока под ним находится окно. Высокая контрастность сохраняет панель.

**Приветствие** (начиная с 3.3): после входа или разблокировки Aether Shell пишет от руки короткое приветствие на весь
экран поверх размытой картинки вашего рабочего стола, а панели появляются, когда оно заканчивается: «Salut», «Hello» или
«Hola», с вашим именем, если вы его ввели. При разблокировке оно уже на месте — вместо рабочего стола. Коснитесь,
щёлкните или нажмите Esc, чтобы пропустить его. Программа установки спрашивает имя необязательно (начиная с 3.5);
«Параметры → Приветствие» выключает его и задаёт язык и имя. Если файл картинки перемещён или удалён, приветствие
использует копию, которую хранит Windows. Имя и ваша картинка остаются на этом ПК; ни то ни другое никуда не отправляется
и не записывается в журнал, а очистка поля удаляет имя. Оно появляется только после того, как Windows вас впустила; сам
экран входа Windows не меняется. При входе оно появляется, как только Windows запускает Aether, а это может произойти
уже после рабочего стола.

**Касание** (начиная с 3.3): прокручивайте любой длинный список или страницу пальцем; она следует за ним напрямую,
скользит дальше, когда вы отпускаете, и мягко возвращается за любым из концов. Касание срабатывает, когда вы поднимаете
палец, прокрутка никогда не срабатывает как действие, а удержание элемента на верхней панели или в Dock открывает его
меню (удерживайте и двигайте, чтобы переупорядочить Dock). Проведите внутрь от верхнего или нижнего края экрана, чтобы
вернуть скрытую панель. В быстрых параметрах проводите вверх или вниз, чтобы переходить между страницами. На ползунке
двигайте в сторону, чтобы изменить его, или коснитесь нужного места; прокрутка вверх или вниз прокручивает страницу.
Ползунок в параметрах вступает в силу, когда вы его отпускаете.

**Автоскрытие** (Alpha 3) настраивается отдельно для каждой панели: «Параметры → Dock → **Автоматически скрывать Dock**» и
«Параметры → Верхняя панель → **Автоматически скрывать верхнюю панель**». Обе выключены по умолчанию. Панель с
автоскрытием уезжает, пока её закрывает окно приложения. Задержите указатель на нижнем краю экрана, чтобы вернуть Dock, а
на самом верхнем краю, без отступа, — на четверть секунды, чтобы вернуть верхнюю панель; если уйти раньше, возврат
отменяется, так что вкладки и кнопки закрытия приложений остаются свободными. Панель остаётся, пока вы ею пользуетесь
или открыто одно из её меню или панелей, и вскоре снова скрывается. На рабочем столе панели возвращаются, даже если
позади есть окна («Показать рабочий стол»). Панель с автоскрытием не резервирует место на экране, поэтому развёрнутые
окна занимают весь экран, а появившаяся панель выводится поверх них, как собственная панель задач Windows с автоскрытием.

В «Рабочий стол» также есть «Импортировать закрепления панели задач Windows». Он читает доступные поддерживаемые
закреплённые ярлыки и добавляет недостающие записи, не изменяя закрепления Windows и не заменяя ваши закрепления Aether.
Некоторые закрепления Windows 11 и их исходный порядок недоступны. Режим замены импортирует поддерживаемые закрепления и
один раз добавляет проводник. Автоматическая синхронизация добавляет новые доступные закрепления при запуске, при
включении синхронизации или перезапуске проводника; она сохраняет порядок пользователя и явные удаления. Ручной импорт
может вернуть удалённые закрепления. В «Оформление» находятся переключатель автоматической синхронизации, тема и
акцент, предустановки значков и элементы управления анимацией.

В Dock-кандидате есть элементы «Пуск», «Поиск» и «Представление задач». Перетаскивайте закреплённые значки, чтобы
изменить их сохранённый порядок; перетаскивание значка, который только запущен, меняет порядок в этом сеансе, не
закрепляя его. Поддерживаемые метаданные значков профилей по окнам могут различать профили Chrome; если метаданных нет,
значок остаётся обобщённым. Контекстные меню Dock предлагают применимые действия с окном, нового экземпляра и закрепления,
не угадывая профиль.

Меню верхней панели открывают параметры часов, питания, звука и сети. Видимая замыкающая стрелка нативной панели задач
была убрана в Alpha 2; начиная с Alpha 3 доступ к собственной области переполнения уведомлений Windows даёт стрелка
скрытых значков. Восстановление остаётся доступным через параметры «Рабочий стол», «Выйти» и отдельную команду
восстановления. Внутренний путь приостановки и возобновления для совместимости остаётся внутренним.

Чтобы вернуть нативную панель, отключите параметр «Рабочий стол» или выберите «Выйти» в меню верхней панели.

Из папки установки команда `AetherShell.exe --restore-taskbar` просит работающий экземпляр отключить режим. Когда Aether
Shell не запущен, та же команда сама возвращает панель задач Windows:
- она использует состояние, сохранённое до того, как панель задач была скрыта;
- она выключает режим;
- она показывает результат.

`AetherShell.exe --quit` просит работающий экземпляр завершиться и ничего не делает, если такого нет.

Отдельная программа восстановления возвращает панель задач после сбоя приложения, а приложение делает то же самое, если
завершилась его программа восстановления. **Восстановление** или **Удаление** в «Параметры Windows > Приложения >
Установленные приложения» тоже возвращают панель задач, которую Aether Shell оставил скрытой. Восстановление сохраняет
ваши параметры, включая выбор в «Рабочий стол», поэтому при следующем запуске Aether Shell снова скроет панель задач,
если вы не выключите параметр. Если ничего из этого не помогает, завершите процессы Aether Shell в диспетчере задач и
перезапустите проводник Windows. Восстановление при всех сбоях и во всех версиях Windows пока не проверено; прочитайте
известные ограничения, прежде чем включать этот режим.

Локальные данные хранятся в `%LOCALAPPDATA%\AetherShell`: параметры, кэш, обновления и журналы ограниченного размера.
Откройте папку журналов в «Общие». Базовый экспорт диагностики содержит версию продукта и сборку Windows; прежде чем
делиться файлами, просмотрите их сами. «Сбросить значения по умолчанию» запрашивает подтверждение и сохраняет резервную
копию параметров. При удалении данные пользователя сохраняются, если не выбрано явное удаление.

О текущих пробелах в проверке см. [известные ограничения](../../../KNOWN_LIMITATIONS.md) (на английском).
