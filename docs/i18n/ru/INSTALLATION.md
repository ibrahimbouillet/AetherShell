Используйте только установочный файл со [страницы выпусков официального репозитория](https://github.com/ibrahimbouillet/AetherShell/releases).
Текущий выпуск, Alpha 4 [0.4.0-alpha.4](https://github.com/ibrahimbouillet/AetherShell/releases/tag/v0.4.0-alpha.4), —
предварительная версия для ручной установки; более широкая проверка Версии 1 остаётся открытой. Более ранний выпуск
[0.2.0-alpha.2](https://github.com/ibrahimbouillet/AetherShell/releases/tag/v0.2.0-alpha.2) остаётся доступным.

Запускайте установку от имени обычного пользователя Windows. Начиная с Alpha 4 программа установки говорит на языке,
выбранном вами в параметрах Aether Shell, а если выбора нет — на языке интерфейса вашей Windows (подойдёт любой из
41 языка интерфейса), и по-английски в остальных случаях. Завершив установку, она скачивает из выпуска языки
интерфейса, которые есть в вашей Windows (по несколько десятков КБ каждый); если сети нет, Aether Shell скачает их при
запуске. Мастер объясняет, что это за продукт, показывает
лицензию MIT и позволяет выбрать папку (по умолчанию `%LOCALAPPDATA%\Programs\AetherShell`), ярлыки и необязательный
автозапуск. Он устанавливает постоянный загрузчик, программу обслуживания и версионные файлы программы. Он может
создать ярлык в меню «Пуск» и запись для одного пользователя в разделе «Установленные приложения» Windows. Права
администратора и замена проводника не используются. При новой интерактивной установке (начиная с Alpha 2) пункт
**Запускать при входе** явно выбран: снимите флажок перед установкой, чтобы отказаться. Согласие на установку сохраняет
этот выбор; уже сохранённый выбор и отключение в диспетчере задач учитываются. Тихая установка включает автозапуск
только с явным флагом `--start-with-windows`; `--no-start-with-windows` выбирает «выключено». Переносимые профили
остаются выключенными до согласия. Порядком запуска при входе управляет Windows, и она может его задержать.

Оболочка V2 по умолчанию визуально заменяет панель задач Windows при запуске Aether Shell. Программа установки сообщает
об этом поведении; у приложения есть программа восстановления и возможность отказа в **«Параметры → Рабочий стол»**.
Обычный выход возвращает панель задач Windows. Проводник продолжает работать, а параметры Windows по-прежнему настраивают
Windows, а не Aether Shell. Ограничения восстановления и аварийные команды описаны в
[руководстве пользователя](USER_GUIDE.md).

Неподписанные файлы приложения и установки могут вызывать SmartScreen. У этой альфа-версии нет сертификата издателя
Authenticode. Проверьте точный источник выпуска и SHA-256, прежде чем решать, запускать ли файл:

```powershell
Get-FileHash .\AetherShell-0.4.0-alpha.4-win-x64-setup.exe -Algorithm SHA256
```

Сравните с соответствующим файлом контрольных сумм. Одна контрольная сумма не подтверждает подлинность издателя.
Автоматические обновления дополнительно требуют подписанный манифест выпуска, описанный в
[UPDATE_AND_ROLLBACK](../../../UPDATE_AND_ROLLBACK.md) (на английском).

Чтобы восстановить активную версию её программой установки, выберите «Установленные приложения» → Aether Shell →
«Изменить». Удаление запрашивает штатное завершение приложения и убирает только зарегистрированные записи и файлы
установки. По умолчанию данные пользователя сохраняются; чтобы удалить параметры, кэш и журналы, явно выберите
удаление. Более старая установка отклоняется, если переход на старую версию явно не разрешён. Сохраните резервную копию
данных пользователя перед любым намеренным переходом на старую версию.

Тихие команды ниже используют программу обслуживания внутри папки установки; имя скачанного установочного файла
включает версию и архитектуру. Указывайте абсолютные пути:

```powershell
.\AetherShellSetup.exe --silent --no-launch
.\AetherShellSetup.exe --silent --repair --no-launch
.\AetherShellSetup.exe --silent --uninstall --keep-user-data
```

Параметры: `--install-root <папка>`, `--data-dir <папка>`, `--no-shortcuts`, `--no-launch`,
`--start-with-windows` (явное согласие), `--repair`, `--uninstall`, `--keep-user-data`,
`--no-start-with-windows` (явный отказ),
`--remove-user-data`, `--allow-downgrade`, `--log <файл>`. Тихий режим никогда не задаёт вопросов. Коды завершения:
0 — успех, 1 — сбой операции, 2 — недопустимые аргументы или сбой настройки пути. Обычный графический интерфейс не даёт
закрыть окно во время выполняемой операции; отмена и проверка самоудаления отслеживаются в
[KNOWN_LIMITATIONS](../../../KNOWN_LIMITATIONS.md) (на английском).
