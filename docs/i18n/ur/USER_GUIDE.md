# Aether Shell کا استعمال

Aether Shell کو اسٹارٹ مینو کے شارٹ کٹ یا انسٹال شدہ لانچر سے شروع کریں۔ یہ ڈیسک ٹاپ پر دو حصے کھولتا ہے: نیچے کی طرف Dock اور اوپر
کی طرف اوپری اسٹیٹس بار۔ Windows ایکسپلورر معمول کے مطابق چلتا رہتا ہے۔ Dock کے آئٹمز کے سیاقی مینو ہیں۔ اوپری بار کا لوگو منتخب کر
کے اس کا مینو کھولیں، جس میں ترتیبات اور بند کریں بھی موجود ہیں۔

تلاش Dock سے یا Ctrl+Alt+Space سے کھولیں۔ کسی ایپلیکیشن کا نام ٹائپ کریں، اوپر/نیچے سے منتخب کریں، اور کھولنے کے لیے Enter دبائیں۔
Esc تلاش کی ونڈو بند کرتا ہے، اسی طرح کچھ اور استعمال کرنا بھی، اور ہر بار کھلنے پر یہ خالی شروع ہوتی ہے۔ ڈیوائس مینیجر جیسے Windows
کے اپنے ٹولز بھی مل جاتے ہیں۔ صرف دریافت شدہ ایپلیکیشن اندراجات ہی شروع کیے جا سکتے ہیں؛ ٹائپ کیا گیا متن کبھی شیل کمانڈ نہیں ہوتا۔
Ctrl+Alt+D توجہ Dock پر لاتا ہے۔ دونوں شارٹ کٹس ترتیبات ← عمومی میں بدلے جا سکتے ہیں؛ ٹکراؤ کی اطلاع وہیں دی جاتی ہے۔

Dock پن کی گئی ایپس کو دوسری چلتی ہوئی ایپس سے الگ کرتا ہے۔ اندراجات کو پن/ان پن کرنے اور ترتیب بدلنے، اور سائز، بڑا کرنے اور حرکت کو
ایڈجسٹ کرنے کے لیے اس کا سیاقی مینو یا ترتیبات ← Dock استعمال کریں۔ چلتی ہوئی ایپ کو اس کے Dock آئٹم سے فعال کیا جا سکتا ہے۔ کچھ UWP
ونڈوز کی نسبت ابھی جانچ کی محتاج ہے۔ Alpha 3: کسی چلتی ہوئی ایپ پر ماؤس لے جانے سے اس کا نشان چوڑا ہو جاتا ہے اور ذرا سے وقفے کے بعد
اس کی ونڈوز کے پیش نظاروں والا ایک کارڈ دکھائی دیتا ہے۔ اس ونڈو پر جانے کے لیے کسی پیش نظارے پر کلک کریں، یا صرف اسی ایک ونڈو کو معمول
کے مطابق بند ہونے کا کہنے کے لیے اس کے بند کرنے کے بٹن پر کلک کریں؛ بند ہونے کا فیصلہ ایپ کرتی ہے (مثلاً محفوظ کرنے کا پوچھنے کے بعد)۔

اوپری بار دستاویز شدہ Windows API سے لیے گئے لمحاتی منظر دکھاتا ہے۔ نامعلوم حالت نامعلوم ہی رہتی ہے۔ بیٹری کے بغیر ڈیسک ٹاپ پی سی بیٹری
کا آئٹم چھپا سکتا ہے۔ "مائیکروفون استعمال میں ہے" کا اشارہ معاون نہیں؛ آلے کی دستیابی/خاموشی کی معلومات الگ ہیں۔ آؤٹ پٹ والیوم بدلنے یا
آواز بند کرنے کے لیے دستیاب آڈیو کنٹرولز پر صرف تب کلک کریں جب آپ واقعی ایسا کرنا چاہیں۔ اوپری بار کبھی کسی نیٹ ورک کا نام نہیں دکھاتا۔
3.3 سے: فوری ترتیبات میں Wi-Fi ٹائل کا تیر آپ کے آس پاس کے نیٹ ورکس ان کے سگنل کے ساتھ دکھاتا ہے۔ شامل ہونے کے لیے کوئی ایک منتخب کریں؛
ضرورت ہو تو Aether اس کا پاس ورڈ مانگتا ہے، اور Windows اسے محفوظ رکھتا ہے۔ نام اور پاس ورڈ کبھی لاگ میں درج یا کہیں بھیجے نہیں جاتے۔
Alpha 2 کی بورڈ آئٹم سے Win+Space کے ذریعے ان پٹ زبان بدلنا اور ظاہر موسم آئٹم سے موسم کی ترتیبات شامل کرتا ہے۔ نیٹ ورک/آڈیو/بیٹری
کا گروپ شدہ عمل Aether کے فوری کنٹرولز کھولتا ہے، جن میں Windows کے فعال سیشن فراہم کرنے پر میڈیا کنٹرول، والیوم، معاون چمک اور سسٹم
کے اعمال کی ٹائلز شامل ہیں۔ غیر معاون سوئچز کسی آلے کو بدلنے کا دکھاوا کرنے کے بجائے متعلقہ Windows کنٹرولز کھولتے ہیں۔ حقیقی آلات پر
جانچ ابھی محدود ہے۔ مائیکروفون پر کلک اینڈ پوائنٹ کو خاموش/غیر خاموش کرتا ہے؛ اس کا دائیں کلک کا مینو رازداری کی ترتیبات اور **Windows
وائس ٹائپنگ شروع کریں (Win+H)** پیش کرتا ہے۔ آواز کا عمل Windows سے فعال خانے میں ڈکٹیشن کھولنے کا کہنے سے پہلے توجہ پچھلی ایپلیکیشن
پر لوٹا دیتا ہے۔ ڈکٹیشن کی دستیابی، مائیکروفون کی اجازت اور پروسیسنگ Windows کے اختیار میں ہیں؛ Aether Shell آواز ریکارڈ یا محفوظ نہیں
کرتا۔ خودکار ٹیسٹس حقیقی ڈکٹیشن نہیں چلاتے۔

Alpha 3 اوپری بار میں تین داخلی راستے شامل کرتا ہے۔ Windows کا نوٹیفکیشن سینٹر کھولنے کے لیے تاریخ اور وقت پر کلک کریں (Windows 11 میں
Win+N، Windows 10 میں Win+A)؛ اس کا مینو کیلنڈر بھی کھولتا ہے۔ Aether کبھی آپ کی اطلاعات نہیں پڑھتا، نہ صاف کرتا ہے نہ گنتا ہے۔ چھوٹا
تیر عین اپنے نیچے Windows کے اپنے نوٹیفکیشن ایریا کے چھپے آئیکنز کھولتا ہے؛ ان کے کھلے رہنے تک تیر اوپر کی طرف رہتا ہے، اور دوسرا کلک
انہیں بند کر دیتا ہے۔ ترتیبات ← اوپری بار ← **چھپے آئیکنز کا بٹن دکھائیں** سے تیر چھپائیں۔ نیٹ ورک/آڈیو/بیٹری کا گروپ شدہ عمل Aether کا
فوری ترتیبات کا پینل کھولتا ہے، جس میں ایک دوسرا صفحہ اور Wi-Fi، Bluetooth، رسائی اور آواز کی آؤٹ پٹ کے تفصیلی مناظر ہیں؛ جو سوئچز
Windows اپنے پاس رکھتا ہے وہ Windows کی ترتیبات کا متعلقہ صفحہ کھولتے ہیں۔ Windows 11 پر اسی صفحے کا **Windows فوری ترتیبات استعمال
کریں (Windows 11)** اس کے بجائے Windows کا اپنا پینل کھولتا ہے۔

**زبان** (Alpha 4): Aether Shell، سیٹ اپ سمیت، انگریزی، چینی (آسان)، ہندی، ہسپانوی، فرانسیسی، پرتگالی، روسی، عربی، بنگالی اور اردو
بولتا ہے۔ ترتیبات ← **زبان** ان میں سے ایک منتخب کرتی ہے؛ **Windows کی پیروی کریں**، جو ڈیفالٹ ہے، آپ کی Windows ڈسپلے زبانوں کو آپ کی
ترتیب کے مطابق دیکھتا ہے اور دس میں سے پہلی لیتا ہے، ورنہ انگریزی۔ تبدیلی فوراً بارز، مینیوز، تلاش اور ترتیبات پر لاگو ہوتی ہے، اور آپ کا
انتخاب آپ کی ترتیبات میں محفوظ رہتا ہے جنہیں ہر ورژن پڑھتا ہے: نیا ورژن، مرمت یا دوبارہ انسٹالیشن اسے پھر سے پا لیتے ہیں، اور سیٹ اپ،
اپ ڈیٹر اور لانچر یہی زبان بولتے ہیں۔ منتخب زبان کے ساتھ اوپری بار تاریخ اسی میں لکھتا ہے؛ Windows کی پیروی کرنے پر تاریخ آپ کا Windows
علاقائی فارمیٹ برقرار رکھتی ہے۔ ایپلیکیشنز، فائلوں اور نیٹ ورکس کے نام کبھی ترجمہ نہیں ہوتے۔ تلاش Windows کے ٹولز اور ترتیبات کے صفحات
انٹرفیس کی زبان میں دکھاتی ہے اور انہیں دس میں سے کسی بھی زبان میں ان کے نام سے ڈھونڈ لیتی ہے۔ عربی اور اردو دائیں سے بائیں پڑھی جاتی ہیں۔

ترتیبات میں یہ صفحات ہیں: Dock، اوپری بار، موسم، اپ ڈیٹس، عمومی، کے بارے میں، ڈیسک ٹاپ، ظاہری شکل، خوش آمدید اور زبان۔ موسم شروع میں
بند ہوتا ہے۔ اسے فعال کرنے سے پہلے رضامندی کے ساتھ خودکار Windows لوکیشن یا کوئی دستی لوکیشن منتخب کریں۔ Windows لوکیشن دینے سے انکار کر
سکتا ہے، اس صورت میں نہ کوئی لوکیشن گھڑی جاتی ہے نہ موسم۔ دستی جگہ کی تلاش درج کیا گیا جگہ کا نام Open-Meteo کو بھیجتی ہے؛ پیش گوئیاں
منتخب تقریبی نقاط بھیجتی ہیں۔ یہ Wi-Fi کے نام یا خام IP سے لوکیشن کا اندازہ نہیں لگاتا۔ کیش شدہ پیش گوئیاں چھ گھنٹے بعد ختم ہو جاتی ہیں۔
ڈیٹا کا حوالہ: Open-Meteo.com، CC BY 4.0۔

عمومی میں اسٹارٹ اپ کی رضامندی، حرکت کی ترجیحات اور شارٹ کٹس میں ترمیم شامل ہے۔ نیا انٹرایکٹو سیٹ اپ (Alpha 2 سے) سائن ان پر اسٹارٹ
اپ کو واضح طور پر منتخب رکھتا ہے؛ انکار کے لیے انسٹالیشن سے پہلے یہ اختیار ہٹا دیں۔ موجودہ انتخاب برقرار رکھے جاتے ہیں۔ خاموش سیٹ اپ
کو اسٹارٹ اپ کا واضح فلیگ درکار ہے۔ اسٹارٹ اپ فی صارف اور اختیاری ہے؛ ترتیبات ← عمومی ← لاگو کریں اسے بدل سکتا ہے، اور ٹاسک مینیجر
اسے آزادانہ طور پر بند کر سکتا ہے۔ سائن ان کے بعد شروع ہونے کی ترتیب اور تاخیر Windows طے کرتا ہے؛ یہ Aether کے تیار ہونے سے پہلے
مقامی ڈیسک ٹاپ/ٹاسک بار دکھا سکتا ہے۔ انسٹال شدہ مستحکم لانچر Windows کی غیر معمولی استثنائی کریشز کے بعد محدود بار دوبارہ کوشش کرتا
ہے۔ جان بوجھ کر بند کرنا/اپ ڈیٹ/اَن انسٹال اور عام خرابیاں اسے روک دیتی ہیں؛ کسی عمل کی ضمانت نہیں دی جا سکتی کہ وہ ہر ناکامی کے باوجود
چلتا رہے۔ ہائی کنٹراسٹ اور کم حرکت جہاں معاون ہوں Windows کی پیروی کرتے ہیں۔ "کے بارے میں" صفحے میں MIT لائسنس اور منصوبے کا حوالہ ہے۔

V2 امیدوار ورژن میں ڈیسک ٹاپ میں **Windows ٹاسک بار تبدیل کریں** ہے، جو بطور ڈیفالٹ فعال ہے (D23)۔ محفوظ کیا گیا واضح انکار برقرار رکھا
جاتا ہے۔ ہم آہنگی بحال کرنے کے لیے اس کا نشان ہٹا کر لاگو کریں دبائیں؛ متبادل دوبارہ فعال کرنے کے لیے نشان لگا کر لاگو کریں دبائیں۔ بند
کرنے یا دوسرے صفحے پر جانے سے غیر لاگو تبدیلی رد ہو جاتی ہے۔ متبادل موڈ میں Dock بڑی کی گئی ایپلیکیشنز کے نیچے جگہ مختص کرتا ہے۔ دستی طور
پر رکھی گئی عام ونڈوز کو پھر بھی ہٹانا پڑ سکتا ہے۔ حالت کا پیغام بتاتا ہے کہ متبادل فعال ہے یا دستیاب نہیں۔ Windows کی ترتیبات اپنا مقامی
ٹاسک بار صفحہ رکھتی ہیں؛ Aether Shell کا رویہ یہاں بدلیں۔ Alpha 3 کے متبادل موڈ میں اہل بڑی کی گئی ونڈوز کو ان کا سائز یا بڑا ہونے کی
حالت بدلے بغیر گول کونے اور ایک باریک کنارہ ملتا ہے؛ Aether بند ہوتے وقت اسے واپس لے لیتا ہے۔ کچھ ایپلیکیشنز اور ونڈو کی اقسام چوکور
کونے رکھتی ہیں۔ 3.3 سے، صرف دونوں بارز کے درمیان۔ دونوں بارز چھپے ہوں تو بڑی کی گئی ونڈو پوری اسکرین لیتی ہے، چوکور۔

Alpha 4 سے (D72): بارز کے درمیان ہر بڑی کی گئی ونڈو گول ہو جاتی ہے، ایپلیکیشن کوئی بھی ہو (براؤزرز، فائل ایکسپلورر، پیکج شدہ اور بلند
اختیارات والی ایپلیکیشنز)، اور اپنے کیپشن بٹن برقرار رکھتی ہے۔ Aether اب ایپلیکیشن کی ونڈو کو بالکل نہیں چھوتا: چاروں کونوں پر رکھے
اس کے اپنے چھوٹے ٹکڑے وہاں موجود ڈیسک ٹاپ کو براہ راست دکھاتے ہیں، گرد باریک کنارے کے ساتھ۔ کونے ہموار (اینٹی ایلیاسڈ) نہیں ہیں۔ بڑی کی
گئی ونڈو کے سامنے کوئی ونڈو انہیں کسی بھی اور چیز کی طرح ڈھانپ لیتی ہے۔

**اوپری بار ڈیسک ٹاپ پر متن کے طور پر** (Alpha 4، D71): ترتیبات ← اوپری بار ← **پیشکش** ← **ڈیسک ٹاپ پر متن** بار کو ہی ہٹا دیتا ہے۔
وہی آئٹمز اسکرین کے بالکل اوپر، براہ راست ڈیسک ٹاپ کی تصویر پر، نیچے کی تصویر کے لحاظ سے چنی گئی ہلکی یا گہری سیاہی میں، نرم ہالے کے
ساتھ لکھے جاتے ہیں۔ یہ پٹی ونڈوز سے خالی رہتی ہے؛ اوپری مارجن اور شیشے کی دھندلاہٹ لاگو نہیں ہوتے۔ **اوپری بار خودکار طور پر چھپائیں**
کے ساتھ، جب نیچے کوئی ونڈو ہو تو متن شیشے کی ایک پٹی پر واپس آ جاتا ہے۔ ہائی کنٹراسٹ بار کو برقرار رکھتا ہے۔

**خوش آمدید** (3.3 سے): سائن ان یا ان لاک کرنے کے بعد Aether Shell آپ کی دھندلی ڈیسک ٹاپ تصویر پر پوری اسکرین میں ہاتھ سے ایک مختصر سلامی
لکھتا ہے، اور اس کے ختم ہونے پر بارز نمودار ہوتے ہیں: "Salut"، "Hello" یا "Hola"، اگر آپ نے نام درج کیا ہو تو اس کے ساتھ۔ ان لاک کرنے پر یہ
ڈیسک ٹاپ کی جگہ پہلے سے موجود ہوتا ہے۔ چھوڑنے کے لیے ٹچ کریں، کلک کریں یا Esc دبائیں۔ سیٹ اپ اختیاری طور پر نام پوچھتا ہے (3.5 سے)؛
ترتیبات ← خوش آمدید اسے بند کرتا اور زبان اور نام طے کرتا ہے۔ اگر تصویر کی فائل منتقل یا حذف ہو گئی ہو تو خوش آمدید وہ نقل استعمال کرتا
ہے جو Windows رکھتا ہے۔ نام اور آپ کی تصویر اسی پی سی پر رہتے ہیں؛ دونوں میں سے کوئی بھی کہیں نہیں بھیجا جاتا اور نہ لاگ میں درج ہوتا ہے،
اور خانہ صاف کرنے سے نام ہٹ جاتا ہے۔ یہ صرف تب ظاہر ہوتا ہے جب Windows آپ کو سائن ان کر چکا ہو؛ Windows کی سائن ان اسکرین بذاتِ خود
نہیں بدلتی۔ سائن ان پر یہ تب ظاہر ہوتا ہے جب Windows، Aether کو شروع کرے، جو ڈیسک ٹاپ کے بعد بھی ہو سکتا ہے۔

**ٹچ** (3.3 سے): کسی بھی لمبی فہرست یا صفحے کو انگلی سے سرکائیں؛ یہ سیدھا انگلی کے ساتھ چلتا ہے، چھوڑنے پر آگے پھسلتا ہے اور کسی بھی
سرے سے آگے جا کر نرمی سے واپس آتا ہے۔ ٹیپ تب کام کرتا ہے جب آپ انگلی اٹھائیں، سرکانا کبھی عمل نہیں کرتا، اور اوپری بار یا Dock کے کسی
آئٹم کو دبائے رکھنے سے اس کا مینو کھلتا ہے (Dock کی ترتیب بدلنے کے لیے دبا کر سرکائیں)۔ چھپا ہوا بار واپس لانے کے لیے اسکرین کے اوپری
یا نچلے کنارے سے اندر کی طرف سوائپ کریں۔ فوری ترتیبات میں صفحات کے درمیان جانے کے لیے اوپر یا نیچے سرکائیں۔ سلائیڈر پر اسے بدلنے کے لیے
پہلو کی طرف سرکائیں یا جہاں چاہیں وہاں ٹیپ کریں؛ وہاں اوپر یا نیچے سرکانا صفحہ اسکرول کرتا ہے۔ ترتیبات کا سلائیڈر چھوڑنے پر نافذ ہوتا ہے۔

**خودکار چھپانا** (Alpha 3) ہر بار کے لیے الگ ترتیب دیا جاتا ہے: ترتیبات ← Dock ← **Dock خودکار طور پر چھپائیں** اور ترتیبات ← اوپری
بار ← **اوپری بار خودکار طور پر چھپائیں**۔ دونوں بطور ڈیفالٹ بند ہیں۔ خودکار چھپنے والا بار ہٹ جاتا ہے جب کوئی ایپلیکیشن ونڈو اسے ڈھانپ
لے۔ Dock واپس لانے کے لیے پوائنٹر اسکرین کے نچلے کنارے پر رکھیں، یا اوپری بار واپس لانے کے لیے بغیر کسی مارجن کے بالکل اوپری کنارے پر
چوتھائی سیکنڈ رکھیں؛ اس سے پہلے ہٹ جانا اسے منسوخ کر دیتا ہے، تاکہ ایپلیکیشنز کے ٹیبز اور بند کرنے کے بٹن آزاد رہیں۔ یہ اس وقت تک رہتا
ہے جب تک آپ اسے استعمال کر رہے ہوں یا اس کا کوئی مینو یا پینل کھلا ہو، اور تھوڑی دیر بعد پھر چھپ جاتا ہے۔ ڈیسک ٹاپ پر بارز واپس آ جاتے
ہیں، پیچھے ونڈوز ہوں تب بھی (ڈیسک ٹاپ دکھائیں)۔ خودکار چھپنے والا بار اسکرین پر کوئی جگہ مختص نہیں کرتا، اس لیے بڑی کی گئی ونڈوز پوری
اسکرین بھر دیتی ہیں اور ظاہر ہونے والا بار ان کے اوپر آتا ہے، Windows کے اپنے خودکار چھپنے والے ٹاسک بار کی طرح۔

ڈیسک ٹاپ میں Windows ٹاسک بار کے پن درآمد کریں بھی ہے۔ یہ دستیاب معاون پن شدہ شارٹ کٹس پڑھتا ہے اور Windows کے پن بدلے یا آپ کے
Aether پن تبدیل کیے بغیر غائب اندراجات شامل کرتا ہے۔ Windows 11 کے کچھ پن اور ان کی اصل ترتیب دستیاب نہیں۔ متبادل موڈ معاون پن درآمد
کرتا ہے اور ایک بار فائل ایکسپلورر شامل کرتا ہے۔ خودکار مطابقت پذیری اسٹارٹ اپ پر، مطابقت پذیری فعال کرنے پر یا ایکسپلورر کے دوبارہ
شروع ہونے پر نئے دستیاب پن شامل کرتی ہے؛ یہ صارف کی ترتیب اور واضح طور پر ہٹائے گئے آئٹمز برقرار رکھتی ہے۔ دستی درآمد ہٹائے گئے پن
بحال کر سکتی ہے۔ ظاہری شکل میں خودکار مطابقت پذیری کا سوئچ، تھیم/ایکسنٹ، آئیکنز کے پہلے سے طے سائز اور حرکت کے کنٹرولز ہیں۔

امیدوار Dock میں اسٹارٹ، تلاش اور ٹاسک ویو کے اندراجات ہیں۔ پن شدہ آئیکنز کی محفوظ ترتیب بدلنے کے لیے انہیں گھسیٹیں؛ صرف چلتے ہوئے کسی
آئیکن کو گھسیٹنا اسے پن کیے بغیر اس سیشن کی ترتیب بدلتا ہے۔ معاون فی ونڈو پروفائل آئیکن کا میٹا ڈیٹا Chrome کے پروفائلز میں فرق کر
سکتا ہے؛ میٹا ڈیٹا نہ ہو تو آئیکن عمومی رہتا ہے۔ Dock کے سیاقی مینو کسی پروفائل کا اندازہ لگائے بغیر قابل اطلاق ونڈو/نئی کاپی/پن کے
اعمال پیش کرتے ہیں۔

اوپری بار کے مینو گھڑی، پاور، آواز اور نیٹ ورک کی ترتیبات تک رسائی دیتے ہیں۔ مقامی ٹاسک بار کے آخر میں ظاہر ہونے والا تیر Alpha 2 میں
ہٹا دیا گیا؛ Alpha 3 سے اس کے بجائے چھپے آئیکنز کا تیر Windows کے اپنے نوٹیفکیشن ایریا کے اضافی آئیکنز تک رسائی دیتا ہے۔ بحالی ڈیسک ٹاپ
کی ترتیبات، بند کریں اور الگ بحالی کمانڈ کے ذریعے دستیاب رہتی ہے۔ مطابقت کے لیے معطلی/دوبارہ آغاز کا راستہ اندرونی ہی رہتا ہے۔

مقامی بار بحال کرنے کے لیے ڈیسک ٹاپ کا اختیار بند کریں یا اوپری بار کے مینو سے بند کریں منتخب کریں۔

انسٹالیشن فولڈر سے `AetherShell.exe --restore-taskbar` چلتی ہوئی کاپی سے موڈ بند کرنے کو کہتا ہے۔ جب Aether Shell نہ چل رہا ہو تو یہی
کمانڈ خود Windows ٹاسک بار بحال کرتی ہے:
- یہ ٹاسک بار چھپانے سے پہلے محفوظ کی گئی حالت استعمال کرتی ہے؛
- یہ موڈ بند کرتی ہے؛
- یہ نتیجہ دکھاتی ہے۔

`AetherShell.exe --quit` چلتی ہوئی کاپی سے بند ہونے کو کہتا ہے، ورنہ کچھ نہیں کرتا۔

ایک الگ بحالی مددگار ایپلیکیشن کی ناکامی کے بعد ٹاسک بار بحال کرتا ہے، اور اگر مددگار بند ہو جائے تو ایپلیکیشن بھی یہی کرتی ہے۔ Windows
کی ترتیبات > ایپس > انسٹال شدہ ایپس میں **مرمت** یا **اَن انسٹال** بھی Aether Shell کا چھپایا ہوا ٹاسک بار بحال کرتے ہیں۔ مرمت آپ کی
ترتیبات، بشمول ڈیسک ٹاپ کا انتخاب، برقرار رکھتی ہے، اس لیے جب تک آپ اختیار بند نہ کریں Aether Shell اگلی بار شروع ہونے پر ٹاسک بار پھر
چھپا دیتا ہے۔ اگر ان میں سے کچھ بھی کام نہ کرے تو ٹاسک مینیجر میں Aether Shell کے پروسیس ختم کریں اور Windows ایکسپلورر دوبارہ شروع
کریں۔ تمام ناکامیوں اور Windows کے تمام ورژنز میں بحالی کی ابھی جانچ نہیں ہوئی؛ یہ موڈ فعال کرنے سے پہلے معلوم حدود دیکھیں۔

مقامی ڈیٹا `%LOCALAPPDATA%\AetherShell` میں رہتا ہے: ترتیبات، کیش، اپ ڈیٹس اور محدود لاگز۔ عمومی سے لاگ فولڈر کھولیں۔ بنیادی تشخیصی
برآمد میں پروڈکٹ کا ورژن اور Windows بلڈ ہوتا ہے؛ کوئی بھی فائل شیئر کرنے سے پہلے خود دیکھ لیں۔ ڈیفالٹس ری سیٹ کرنا تصدیق مانگتا ہے
اور ترتیبات کا بیک اپ رکھتا ہے۔ جب تک ہٹانا واضح طور پر منتخب نہ کیا جائے، اَن انسٹال صارف کا ڈیٹا برقرار رکھتا ہے۔
