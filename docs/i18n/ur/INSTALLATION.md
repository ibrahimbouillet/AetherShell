# انسٹالیشن

صرف [سرکاری ریپوزٹری کے ریلیزز صفحے](https://github.com/ibrahimbouillet/AetherShell/releases) سے سیٹ اپ ایگزیکیوٹیبل استعمال کریں۔
موجودہ ریلیز، 3.5 [0.3.5-alpha.3](https://github.com/ibrahimbouillet/AetherShell/releases/tag/v0.3.5-alpha.3)، دستی انسٹالیشن کا
ایک پیش نظارہ ہے؛ ورژن 1 کی وسیع جانچ ابھی باقی ہے۔ پچھلا
[0.2.0-alpha.2](https://github.com/ibrahimbouillet/AetherShell/releases/tag/v0.2.0-alpha.2) اب بھی دستیاب ہے۔

سیٹ اپ اپنے عام Windows صارف کے طور پر چلائیں۔ Alpha 4 سے سیٹ اپ وہ زبان بولتا ہے جو آپ نے Aether Shell کی ترتیبات میں منتخب کی ہو،
ورنہ آپ کی Windows ڈسپلے زبانوں میں سے پہلی وہ زبان جو انٹرفیس کی دس زبانوں میں ہو، اور اس کے علاوہ انگریزی۔ وزرڈ پروڈکٹ کی وضاحت
کرتا ہے، MIT لائسنس دکھاتا ہے، اور آپ کو ایک فولڈر (ڈیفالٹ `%LOCALAPPDATA%\Programs\AetherShell`)، شارٹ کٹس اور اختیاری اسٹارٹ
اپ منتخب کرنے دیتا ہے۔ یہ ایک مستحکم لانچر، ایک دیکھ بھال کا سیٹ اپ اور ورژن والی پروگرام فائلیں انسٹال کرتا ہے۔ یہ اسٹارٹ مینو میں
ایک شارٹ کٹ اور Windows کی انسٹال شدہ ایپس میں فی صارف ایک اندراج بنا سکتا ہے۔ نہ ایڈمنسٹریٹر کے حقوق استعمال ہوتے ہیں نہ ایکسپلورر کی
جگہ لی جاتی ہے۔ نئی انٹرایکٹو انسٹالیشن میں (Alpha 2 سے) **سائن ان پر شروع کریں** واضح طور پر منتخب ہوتا ہے: انکار کے لیے انسٹال سے پہلے
اس کا نشان ہٹا دیں۔ سیٹ اپ قبول کرنے سے یہ انتخاب محفوظ ہو جاتا ہے؛ پہلے سے محفوظ انتخاب اور ٹاسک مینیجر میں بند کرنے کا احترام کیا
جاتا ہے۔ خاموش سیٹ اپ صرف واضح فلیگ `--start-with-windows` کے ساتھ اسٹارٹ اپ چالو کرتا ہے؛ `--no-start-with-windows` بند منتخب کرتا
ہے۔ پورٹیبل پروفائلز رضامندی تک بند رہتی ہیں۔ سائن ان پر شروع ہونے کی ترتیب Windows طے کرتا ہے اور اس میں تاخیر کر سکتا ہے۔

V2 شیل بطور ڈیفالٹ Aether Shell شروع ہونے پر بصری طور پر Windows ٹاسک بار کی جگہ لیتا ہے۔ سیٹ اپ اس رویے کو ظاہر کرتا ہے؛ ایپ ایک
بحالی مددگار اور **ترتیبات ← ڈیسک ٹاپ** میں انکار کا اختیار رکھتی ہے۔ معمول کے مطابق بند ہونے پر Windows ٹاسک بار واپس آ جاتا ہے۔
ایکسپلورر چلتا رہتا ہے، اور Windows کی ترتیبات Aether Shell کو نہیں بلکہ Windows کو ہی ترتیب دیتی ہیں۔ بحالی کی حدود اور ہنگامی کمانڈز
[صارف گائیڈ](USER_GUIDE.md) میں ہیں۔

بغیر دستخط والی ایپلیکیشن/سیٹ اپ بائنریز SmartScreen کو متحرک کر سکتی ہیں۔ اس الفا کے پاس Authenticode ناشر سرٹیفکیٹ نہیں ہے۔
چلانے کا فیصلہ کرنے سے پہلے ریلیز کا درست ماخذ اور SHA-256 جانچیں:

</div>

<div dir="ltr">

```powershell
Get-FileHash .\AetherShell-0.3.5-alpha.3-win-x64-setup.exe -Algorithm SHA256
```

</div>

<div dir="rtl">

متعلقہ چیک سم فائل سے موازنہ کریں۔ صرف چیک سم سے ناشر کی تصدیق نہیں ہوتی۔ خودکار اپ ڈیٹس کے لیے مزید
[UPDATE_AND_ROLLBACK](../../../UPDATE_AND_ROLLBACK.md) (انگریزی میں) میں بیان کردہ دستخط شدہ ریلیز مینی فیسٹ درکار ہے۔

فعال ورژن کو اس کے مطابق سیٹ اپ سے مرمت کرنے کے لیے انسٹال شدہ ایپس ← Aether Shell ← ترمیم استعمال کریں۔ اَن انسٹال ایپ کو
شائستگی سے بند ہونے کو کہتا ہے اور صرف انسٹالیشن کے رجسٹر شدہ اندراجات اور فائلیں ہٹاتا ہے۔ صارف کا ڈیٹا رکھنا ڈیفالٹ ہے؛
ترتیبات/کیش/لاگز حذف کرنے کے لیے واضح طور پر ہٹانا منتخب کریں۔ پرانا سیٹ اپ مسترد ہو جاتا ہے جب تک ڈاؤن گریڈ کی واضح اجازت نہ دی گئی
ہو۔ کسی بھی جان بوجھ کر ڈاؤن گریڈ سے پہلے صارف کے ڈیٹا کا بیک اپ رکھیں۔

نیچے کی خاموش کمانڈز انسٹالیشن فولڈر کے اندر دیکھ بھال کا ایگزیکیوٹیبل استعمال کرتی ہیں؛ ڈاؤن لوڈ کی گئی سیٹ اپ فائل کے نام میں ورژن
اور آرکیٹیکچر شامل ہوتے ہیں۔ مکمل (absolute) حسبِ ضرورت راستے استعمال کریں:

</div>

<div dir="ltr">

```powershell
.\AetherShellSetup.exe --silent --no-launch
.\AetherShellSetup.exe --silent --repair --no-launch
.\AetherShellSetup.exe --silent --uninstall --keep-user-data
```

</div>

<div dir="rtl">

اختیارات: `--install-root <فولڈر>`، `--data-dir <فولڈر>`، `--no-shortcuts`، `--no-launch`، `--start-with-windows` (واضح رضامندی)،
`--repair`، `--uninstall`، `--keep-user-data`، `--no-start-with-windows` (واضح انکار)، `--remove-user-data`، `--allow-downgrade`،
`--log <فائل>`۔ خاموش موڈ کبھی کچھ نہیں پوچھتا۔ ایگزٹ کوڈز: 0 کامیابی، 1 عمل کی ناکامی، 2 غلط دلائل/راستے کی ترتیب کی ناکامی۔ عام
گرافیکل انٹرفیس جاری عمل کے دوران بند ہونے نہیں دیتا؛ منسوخی اور خود اَن انسٹال کی جانچ
[KNOWN_LIMITATIONS](../../../KNOWN_LIMITATIONS.md) (انگریزی میں) میں درج ہے۔

</div>
