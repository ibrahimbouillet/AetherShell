# Aether Shell media

Versioned screenshots and release-video references for the public project. Each gallery identifies
the product version, capture source, review status and applicable credits. Keep older releases in
their own directories; create fresh media for a new release rather than relabelling an earlier take.

| Version | Gallery | Status |
| --- | --- | --- |
| 0.3.0-alpha.3 | Not created yet | No capture yet; any take needs D36 readiness and every-frame privacy review |
| 0.2.0-alpha.2 | [Alpha 2 gallery](0.2.0-alpha.2/README.md) | Draft — fresh capture and privacy review pending |

Only selected, reviewed exports belong here. Raw recordings, process metadata, private configuration
and local QC working files stay outside the repository. The capture workflow is documented in
[showcase capture](../showcase-capture.md).

The application source uses the [MIT license](../../LICENSE). Wallpaper photographs and third-party
application marks have separate rights; each gallery records its own credits.
