# Aether Shell

**Ibrahim Bouillet** کا بنایا ہوا Windows کا ایک مقامی ڈیسک ٹاپ انٹرفیس۔ Aether Shell ایک تیرتے ہوئے Dock اور ایک مختصر اوپری
اسٹیٹس بار کو یکجا کرتا ہے، جن کا مواد نرمی سے دھندلا اور نیم شفاف ہے۔ یہ C++20 میں Win32، Direct2D/DirectWrite اور
Windows.UI.Composition کے ساتھ لکھا گیا ہے اور MIT لائسنس کے تحت جاری کیا جاتا ہے۔

> **الفا سافٹ ویئر:** 0.4.0-alpha.4 (Alpha 4) ایک ابتدائی عوامی پیش نظارہ ہے۔ یہ Windows شیل کا مکمل طور پر جانچا ہوا
> متبادل نہیں ہے۔ آزمانے سے پہلے اپنا کام محفوظ کریں اور [معلوم حدود](KNOWN_LIMITATIONS.md) (انگریزی میں) پڑھیں۔

## یہ کیا کرتا ہے

- **Dock:** ایپلیکیشنز کھولنا اور ان کے درمیان آنا جانا، پسندیدہ رکھنا، پن کیے گئے آئیکنز کی ترتیب بدلنا، ماؤس لے جانے پر متحرک
  نشانات اور ونڈوز کے حقیقی پیش نظاروں کے ساتھ چلتی ہوئی ایپس دیکھنا، تلاش کھولنا، اور اسٹارٹ اور ٹاسک ویو تک پہنچنا۔
- **اوپری اسٹیٹس بار:** Windows کی فراہم کردہ گھڑی، ان پٹ زبان، نیٹ ورک، آڈیو اور بیٹری کی حالت دکھاتا ہے۔ تاریخ اور وقت Windows
  کی اطلاعات اور کیلنڈر کھولتے ہیں، ایک تیر Windows کے نوٹیفکیشن ایریا کے چھپے آئیکنز کھولتا ہے، اور اسٹیٹس کا گروپ شدہ عمل Aether کا
  فوری ترتیبات کا پینل کھولتا ہے، جس میں Wi-Fi کی فہرست بھی ہے۔
- **تلاش:** ایپلیکیشنز اور Windows کے اپنے ٹولز، جیسے ڈیوائس مینیجر، سروسز یا کنٹرول پینل کے آئٹمز، تلاش کر کے کھولنا۔
- **خودکار چھپانا:** جب کوئی ایپلیکیشن ونڈو Dock اور اوپری بار کو ڈھانپ لے تو انہیں، ہر ایک کو الگ الگ، ہٹ جانے دیں اور پوائنٹر
  اسکرین کے کنارے تک پہنچنے پر واپس آنے دیں، تاکہ پوری اسکرین کام کے لیے ملے۔
- **41 زبانیں:** سیٹ اپ سمیت پورا انٹرفیس ان 38 زبانوں میں جو Windows 11 پیش کرتا ہے، اور ان کے ساتھ بنگالی، ہندی اور اردو
  میں۔ یہ آپ کی Windows ڈسپلے زبانوں کی پیروی کرتا ہے، یا اس زبان کی جو آپ ترتیبات ← زبان میں منتخب کریں، اور یہ انتخاب ایک ورژن
  سے دوسرے ورژن تک یاد رکھتا ہے۔ ہر زبان ضرورت پڑنے پر ریلیز سے ڈاؤن لوڈ کی جاتی ہے۔ دیکھیں [زبانیں](#زبانیں)۔
- **خوش آمدید:** سائن ان کرنے یا پی سی ان لاک کرنے کے بعد آپ کے دھندلے وال پیپر پر فرانسیسی، انگریزی یا ہسپانوی میں ہاتھ سے لکھی
  اختیاری سلامی۔ سیٹ اپ پوچھ سکتا ہے کہ کس نام سے آپ کو سلام کیا جائے۔
- **موسم:** اختیاری طور پر تقریبی مقام اور پیش گوئی کے لیے Windows کی لوکیشن اجازت استعمال کریں۔ اگر لوکیشن یا نیٹ ورک دستیاب نہ ہو
  تو موسم اندازہ لگانے کے بجائے دستیاب نہیں رہتا۔
- **حرکت اور ظاہری شکل:** بارز، ترتیبات، مینیوز اور سیٹ اپ میں پالے ہوئے شیشے کا ایک ہی غیر جانبدار ڈیزائن؛ ترتیبات میں رواں
  اسکرولنگ؛ جب Aether ٹاسک بار کی جگہ لیتا ہے تو بڑی کی گئی ونڈوز کے گول کونے؛ ہلکی/گہری شکل، کی بورڈ سے نیویگیشن اور کم حرکت کی سہولت۔
- **بحالی:** فی صارف انسٹالر، الگ بحالی مددگار، مرمت/اَن انسٹال کی سہولت، اور Windows ٹاسک بار بحال کرنے کی ایک کمانڈ۔

## Alpha 4 میں نیا کیا ہے

دو انداز: *Liquid*، آپ کی اپنی مرضی سے ترتیب دی گئی دھندلاہٹ کی تہہ پر شفاف پانی جیسا شیشہ، اور *Grain*، پچھلے ورژنز کا پالا ہوا
مواد۔ Liquid میں ترتیبات کی ونڈو صرف اپنے متن اور کنٹرولز کے نیچے کا حصہ دھندلا کرتی ہے اور باقی ہر جگہ شفاف رہتی ہے۔ انٹرفیس
41 زبانیں بولتا ہے، جو ضرورت پڑنے پر ریلیز سے ڈاؤن لوڈ ہوتی ہیں، اور آپ کی Windows ڈسپلے زبان کی پیروی کرتا ہے۔ تلاش نام سے وہ سب
کچھ ڈھونڈ لیتی ہے جو اسٹارٹ ڈھونڈتا ہے۔ موسم درست اور متحرک ہے، اور اس کی اپنی ایک ونڈو ہے۔ اوپری بار آپ کے ڈیسک ٹاپ پر صرف سادہ
متن کی صورت میں بھی رہ سکتا ہے، گھسیٹا گیا آئیکن Dock کو پھیلا دیتا ہے، اور سائن ان کے بعد Aether پہلے سے جلدی شروع ہوتا ہے۔
[ریلیز نوٹس](docs/releases/0.4.0-alpha.4.md) اور [تبدیلیوں کی فہرست](CHANGELOG.md) (انگریزی میں) پڑھیں۔

کی جو آپ ترتیبات ← زبان میں منتخب کریں؛ ہر زبان ضرورت پڑنے پر ریلیز سے ڈاؤن لوڈ کی جاتی ہے۔ یہ دستاویزات نیچے دی گئی دس زبانوں

**Windows کی پیروی کریں** (ڈیفالٹ) آپ کی Windows ڈسپلے زبانوں (ترتیبات ← وقت اور زبان) کو آپ کی ترتیب کے مطابق دیکھتا ہے اور ان
میں سے وہ پہلی لیتا ہے جو Aether Shell بولتا ہے (41 میں سے کوئی بھی)؛ اگر کوئی نہ ہو تو انگریزی۔ **ترتیبات ← زبان** میں
کوئی دوسری منتخب کریں؛ تبدیلی فوراً لاگو ہوتی ہے اور آپ کی
ترتیبات میں محفوظ رہتی ہے جنہیں ہر ورژن پڑھتا ہے: نیا ورژن انسٹال کرنا، مرمت یا دوبارہ انسٹال کرنا اسے برقرار رکھتا ہے، اور سیٹ اپ،
اپ ڈیٹر اور لانچر بھی یہی زبان بولتے ہیں۔ آپ کے یا دوسرے پروگراموں کے نام (ایپلیکیشنز، فائلیں، Wi-Fi نیٹ ورک) کبھی ترجمہ نہیں کیے
جاتے۔ ہاتھ سے لکھا خوش آمدید لاطینی حروف لکھتا ہے، اس لیے یہ فرانسیسی، انگریزی یا ہسپانوی میں سلام کرتا ہے۔ عربی، عبرانی اور اردو دائیں سے
بائیں پڑھی جاتی ہیں: متن اسی کے مطابق تشکیل اور ترتیب پاتا ہے، جبکہ بارز اور پینل اپنی ترتیب برقرار رکھتے ہیں۔ ترجمے
[tools/i18n/languages](tools/i18n/languages) میں ہیں؛ اصلاحات کا خیرمقدم ہے۔

## Windows ٹاسک بار کی جگہ لینا

V2 تجربے میں Aether Shell شروع ہوتے ہی Windows ٹاسک بار چھپ جاتا ہے اور اس کی جگہ Aether کا Dock دکھایا جاتا ہے۔ یہ رویہ بطور ڈیفالٹ
فعال ہے اور **Aether Shell کی ترتیبات ← ڈیسک ٹاپ** میں بند کیا جا سکتا ہے۔ ایکسپلورر چلتا رہتا ہے؛ Aether Shell نہ `explorer.exe` کی
جگہ لیتا ہے، نہ Winlogon شیل بدلتا ہے، اور نہ Windows کی ترتیبات میں خود کو مقامی ٹاسک بار کے طور پر رجسٹر کرتا ہے۔ Aether Shell بند
ہونے پر بحالی مددگار Windows ٹاسک بار واپس لاتا ہے۔ الفا آزمانے سے پہلے [بحالی گائیڈ](docs/i18n/ur/USER_GUIDE.md) پڑھیں۔

## ڈاؤن لوڈ اور انسٹال

[تازہ ترین GitHub ریلیز](https://github.com/ibrahimbouillet/AetherShell/releases/latest) سے **x64 سیٹ اپ ایگزیکیوٹیبل** ڈاؤن لوڈ کریں اور
اس کا SHA-256 ریلیز کی چیک سم فائل سے ملائیں۔ سیٹ اپ اپنے عام Windows صارف کے طور پر چلائیں۔ انسٹالر ٹاسک بار کا رویہ سمجھاتا ہے اور
ایڈمنسٹریٹر کے حقوق نہیں مانگتا۔ نئے سیٹ اپ میں **سائن ان پر شروع کریں** واضح طور پر منتخب ہوتا ہے؛ قبول کرنے سے پہلے آپ یہ اختیار ہٹا
سکتے ہیں۔ پہلے سے محفوظ انتخاب اور ٹاسک مینیجر میں اسٹارٹ اپ بند کرنے کا احترام کیا جاتا ہے۔ سیٹ اپ اس نام کے لیے ایک اختیاری خانہ
بھی دیتا ہے جس سے خوش آمدید آپ کو سلام کرے؛ یہ آپ کے پی سی پر ہی رہتا ہے۔ انسٹال شدہ لانچر غیر معمولی کریشز کے بعد محدود بار دوبارہ کوشش
کر سکتا ہے؛ بند کرنا، بحالی اور اَن انسٹال دستیاب رہتے ہیں۔ اسٹارٹ اپ کا وقت Windows طے کرتا ہے، اس لیے Aether یہ ضمانت نہیں دے سکتا
کہ سائن ان پر اس کا انٹرفیس مقامی ٹاسک بار سے پہلے ظاہر ہوگا۔

یہ الفا دستی انسٹالیشن کے لیے تقسیم کیا جاتا ہے۔ خودکار اپ ڈیٹس کے لیے دستخط شدہ ریلیز مینی فیسٹ درکار ہے؛ کوئی بغیر دستخط والا مینی
فیسٹ شائع نہیں کیا جاتا۔ سیٹ اپ بائنری پر Authenticode دستخط نہیں ہیں، اس لیے Windows ایک SmartScreen وارننگ دکھا سکتا ہے۔ دیکھیں
[انسٹالیشن اور تصدیق](docs/i18n/ur/INSTALLATION.md)۔

## مطابقت

- Windows 11، x64: موجودہ ترقیاتی ہدف۔
- Windows 10 2004+ x64: ڈیزائن کے لحاظ سے معاون، لیکن اس ریلیز میں چلا کر جانچا نہیں گیا۔
- ARM64: چلا کر جانچا نہیں گیا۔

Windows 10 میں پس منظر کی دھندلاہٹ ایک سادہ رنگت استعمال کرتی ہے۔ Dock مقامی ٹاسک بار کی ہر خصوصیت نہیں دہراتا، اور Windows کی
ترتیبات بدستور Windows ٹاسک بار کا انتظام کرتی ہیں۔ مکمل [معلوم حدود](KNOWN_LIMITATIONS.md) (انگریزی میں) دیکھیں۔

## بنانا اور جانچنا

Windows پر Visual Studio C++ Build Tools، ایک Windows SDK، CMake، Ninja اور Python کے ساتھ بنائیں:

</div>

<div dir="ltr">

```powershell
./scripts/build.ps1 -Config release -BuildDir build/release -Test -TestExclude 'network|integration' `
    -CMakeArgs '-DAETHER_WARNINGS_AS_ERRORS=ON'
```

</div>

<div dir="rtl">

فی صارف انسٹالر بنانے اور اس کے پیکج کی رازداری/تازگی کا آڈٹ چلانے کے لیے:

</div>

<div dir="ltr">

```powershell
./scripts/package.ps1 -BuildDir build/release
```

</div>
